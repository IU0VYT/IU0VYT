4.12.0 (09.11.2026)
-------------------
- Язык при первом запуске (i18n.go, syslang_windows.go): если язык ни разу не выбирали
  флагами, программа берёт первый из языков интерфейса Windows пользователя
  (GetUserPreferredUILanguages), который есть среди её 11; если такого нет —
  английский. Выбор, сделанный флагами, сохраняется и действует при перезапусках
  (теперь сохраняется и итальянский, который раньше путался с «нет выбора»). Окна
  сообщений Windows следуют тому же языку. Тест: TestSysLang.
- Переводы: «Да» и «Нет» (столбец Сканирование и меню таблиц) были слишком короткими
  для списка переводимых текстов и оставались на итальянском во всех языках; название
  лицензии на начальной странице оставалось итальянским. Теперь они переведены (4905
  текстов на язык).
- Безопасность, сообщения CodeQL: bw.go записывает байты слов без обрезающих
  преобразований; папка данных из переменной GESTIONE_CANALI_DIR (для тестов)
  очищается и отклоняется при «..»; firmware.js получает простой текст из HTML
  средствами браузера, а не регулярным выражением; verifica/sito/brandcolors.js читает
  ui/gallery.js из папки исходников, а не по пути из командной строки.
- Репозиторий: README.md теперь на английском (главная страница репозитория),
  итальянский оригинал — README.it.md; панель языков с флагами и снимками программы во
  всех README; политика безопасности (.github/SECURITY.md) на английском с переводами
  на остальные 10 языков (.github/security).
- Сайт: обновлены тексты об опознании, руководстве и лицензии; картинка для
  предпросмотра в соцсетях (docs/img/social.png); флаги и снимки программы в docs/img;
  при каждой публикации страницы сообщаются Bing, Яндексу и другим поисковикам,
  использующим IndexNow.
