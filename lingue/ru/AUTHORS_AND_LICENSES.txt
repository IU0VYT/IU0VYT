ОБНОВЛЕНИЕ ПРОШИВКИ QUANSHENG UV-K5 (4.1)
Формат файлов .bin от Quansheng и протокол загрузчика UV-K5 описаны свободными
программами k5prog (Copyright 2023 Jacek Lipkowski SQ5BPF, GNU GPL v3,
https://github.com/sq5bpf/k5prog) и uvtools (egzumer,
https://github.com/egzumer/uvtools). fwk5.go написан с нуля на основе этого описания
для обеспечения совместимости; кода этих программ в пакете нет. verifica/k5/k5ref.js,
используемый только для проверок, загружает код uvtools из папки, указанной тем, кто
выполняет проверку. Спасибо SQ5BPF и egzumer.

ОБНОВЛЕНИЕ ПРОШИВКИ TIDRADIO TD-H3 / TD-H8 И RADTEL RT-730 (4.3)
Протокол загрузчика описан nicsure в проекте TD-H3-Engineering
(https://github.com/nicsure/TD-H3-Engineering, firmware_flash_protocol.txt, с
перехватом обмена программы производителя) и используется его программой TID Station;
то же приветствие из 36 байт есть в программах производителя «H8_IAP» (TIDRADIO) и
«RT730 Update tool» (Radtel). fwtdh.go написан с нуля на основе этого описания для
обеспечения совместимости; кода этих программ в пакете нет. Спасибо nicsure.

ОБНОВЛЕНИЕ ПРОШИВКИ С ЗАГРУЗЧИКОМ 7.x (UV-K5 V3, UV-K1, RA79 V3) (4.4)
Протокол описан и используется свободными программами quansheng_toolkit (Copyright
2026 knoinok, лицензия Apache 2.0, https://github.com/knoinok/quansheng_toolkit,
kradio/dfu.py) и Multi-UVTools (spm81, https://github.com/armel/Multi-UVTools,
js/flash-k1.js). fwk5.go (k5v3Update) написан с нуля на основе этого описания; кода
этих программ в пакете нет.

ОБНОВЛЕНИЕ ПРОШИВКИ RETEVIS RA89 (4.4) И RT85 (4.5)
Протокол получен для обеспечения совместимости из программ Retevis
«RA89-update-software» («TH8600-UpDAta Soft» 2.3) и «RT85 10W_5W_UpData»
(«TH8600-UpDAta Soft» 2.1, retevis.com); программы в пакет не входят. verifica/ra89,
используемый только для проверок, загружает исполняемый файл, указанный тем, кто
выполняет проверку.

RADTEL RT-950 PRO, BAJETON BJ-9000 И RADTEL RT-950 (4.6, 4.7)
4.7: сравнены также программы Radtel RT-950PRO_CPS v1.2.1 и Bajeton BJ-9000_CPS v1.3.3
(bajeton.cn) и загрузчики «RT-950_EnUPDATE», «BJ9000_EnUPDATE» и «Radtel ANC
Bootloader V1.2» (протоколы обновления, для обеспечения совместимости); прошивки
(Radtel radtels.com, Bajeton bajeton.com и bajeton.cn) распознаются только по
отпечатку SHA-256. Ни программ, ни прошивок в пакете нет.
Память каналов и настройки получены для обеспечения совместимости из кода программ
производителя (Radtel RT-950PRO_CPS v1.1.1, v1.2.0, v1.2.1, v1.3.3 и RT-950_EnCPS
«BT-9000_CPS» v1.3.0, radtels.com; Bajeton BJ-9000_CPS v1.1.1) и из примечаний к
прошивкам Radtel; программы в пакет не входят. Использованы также заметки,
опубликованные JA van Hernen (PE1HVH) к его драйверу CHIRP для RT-950 Pro
(https://github.com/pe1hvh/chirp_radtel_rt950pro, лицензия MIT; ответ радиостанции на
команду «F» одинаков с прошивками 0.18 и 0.29), и сообщение 12180 в CHIRP: кода этих
проектов в пакете нет.

ПРОШИВКА .BTU (4.8)
Прошивки .BTU для Radtel RT-910 и RT-900 без Bluetooth и Bajeton BJ-7700 без Bluetooth
отправляются по протоколу программы «Radtel Bootload Tools» (Radtel, radtels.com),
полученному из её кода для обеспечения совместимости: это тот же загрузчик KDH V1.0,
что у Baofeng UV-5RM (bfkdh.go), с приветствием «PROGRAMBT80U». Прошивки (Radtel
radtels.com, Bajeton bajeton.com) распознаются только по отпечатку SHA-256; для RT-900
сравнены также программы производителя «RT900_512 CPS» v1.0.0 и v1.0.2 (512 и 999
каналов). Ни программ, ни прошивок в пакете нет.

Прошивки .kdhx для Radtel RT-470 / RT-495 / RT-630 используют тот же протокол, что
«Bootloader Pro» для UV-25 Plus (fwkdhx.go), с платформой JJCC, указанной программой
Radtel «New RT470 serial Bootloader Pro».
Изменения по сравнению с оригинальными файлами CHIRP (переписывание на Go, только
каналы, приспособление к интерфейсу IU0VYT Flash) описаны в начале каждого файла и в
CHANGELOG.txt с датами версий.

НАСТРОЙКИ, ПОЛУЧЕННЫЕ ИЗ CHIRP (с 3.6)
--------------------------------------
Таблицы настроек радиостанций с драйверами CHIRP (sorgenti/settings_chirp.json)
получены путём выполнения кодом CHIRP (GNU GPL, авторы как выше) чтения и записи
каждого пункта (sorgenti/verifica/chirp/chirpsettings.py): они содержат положение

конвертером и сверяется с кодом CHIRP (sorgenti/verifica/chirp/csvcheck.py, не
входящий в программу).

радиостанциями по программам производителей (с 3.3 также «BF Series CPS», «T17-T18

структура файлов обновления BTECH DMR-6X2; с 4.0 протоколы радиостанций других марок в
