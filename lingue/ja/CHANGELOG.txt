4.10.0（2026/11/07）
-------------------
- インターフェースの言語：「ℹ Info」の右にある旗付きの選択（イタリア語、英語、フランス語、ドイツ語、スペイン語、ポルトガル語、ロシア語、中国語、日本語）。ページ全体をすぐに翻訳し（ui/i18n.js：プログラムから届くものも含め、すべてのテキストを訳文に置き換えます。可変部分のあるテキストや組み立てたメッセージも識別）、Windows のウィンドウのテキストも翻訳します（i18n.go：「開く」と「保存」のメッセージ、タイトル、フィルター）。訳文は ui/lang/<言語>.tsv（キーはイタリア語テキストの 32 ビット FNV-1a）。選んだ言語は設定に保存されます（Settings.Lang、API「lang」）。i18n_test.go がテキスト（ui/*.js、ui/index.html、.go ファイルの文字列）を抽出し、各言語がすべてのテキストを同じ可変部分で持っているかを確認します。説明ファイルは「lingue」フォルダーに翻訳してあります。
- 上部のバー：「アップデート」を削除（自動確認と Info タブの「アップデートを確認」は残ります）。「無線機を識別」を「? ガイド」の隣に配置。
- Radtel RT-890 のファームウェア（fwrt890.go）：Radtel とフリーの .bin ファイル（M7OCM、OEFW）、無線機のローダー（115200 ボー、消去、128 バイトのブロック）。JuantAldea の rt_890_flasher プログラムに基づきます。模擬無線機と M7OCM v3.2 ファームウェアで試験。
- Baofeng DM-1701 / Retevis RT84 のファームウェア（fwdm1701.go）：メーカーの「OutSecurityBin」ファイルを、radio_tool と同じくローダーで USB DFU により書き込み（コマンド 91 31、セクターごとの消去、セクターごとに 2 から番号を振る 1024 バイトのブロック）。0x0800C000 以降のプログラムメモリーだけを書き込み、ローダーには触れません。メーカーの V02.06 ファイルを模擬無線機で試験。
- Baofeng RD-5R と DM-1801 のファームウェア（fwsgl.go）：メーカーの .sgl ファイルを、OpenGD77 の FirmwareLoader や radio_tool と同じく USB HID で書き込み（消去前に無線機が機種キーを確認、32 バイトのブロック、1 KB ごとのチェックサム）。メーカーのファイルを模擬無線機で試験。
- 設定：CHIRP から Feidaxin FD-288A、FD-150A、FD-160A、FD-450A、FD-460A、FD-460UH（fd268.py、同じファミリーの機種のイメージを使用）と Retevis RT76P（空のイメージ）。Baofeng RD-5R と DM-1801（settings_rdty.go、31 項目、qdmr と dmrconfig に基づく）。Baofeng DM-1701（名前、DMR ID、電源オン時のテキスト。16 ビット Unicode のテキスト）。
- テスト：extra_test.go は Windows 以外でのみ実行（Windows で go test が再び動作）。
