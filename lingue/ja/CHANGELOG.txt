4.13.0（2026/11/09）
-------------------
- Quansheng UV-K5 / UV-K5 V3 / UV-K1 用 IJV ファームウェア（drv_ijv.go、新規）：4 つの
  タブ。200 チャンネルの V3（0x0500、8 KiB イメージ）、999 チャンネルの V3 X
  （0x2000-0x9FFF）、V4 と V5（無線機で選択したバンクの 500 チャンネル、24 KiB イメージ：
  固定領域 0x0000-0x1FFF とバンク 0x2000-0x5FFF）。32 バイトのチャンネルレコード。グループ、
  AGC、コンパンダー、スクランブラー、セレコール、TX ロック、ビジーロックは保持。接続：V3 は
  UV-K5 純正プロトコル、V4 と FW5 は IJV 平文プロトコル（応答がなければ純正プロトコル）、FW5 は
  物理読み書き（0x0564/0x0566）と最終保存（0x0576）。アクティブバンクはバイト 0x000B（V4）
  または「CFG5」（FW5）から取得し、書き込み前に再確認：無線機で別のバンクが選ばれていれば何も
  書き込みません。V4 と FW5 は変更ブロックのみ書き込み、校正データ（0x1E00 以降）、FW5 の設定と
  ライセンスは書き込みません。V6 はデータリンクで認識。形式は IJV が公開した CHIRP モジュール
  （3.60、V4.0、V5.0）と RadioManager 4.3.2 の解析から取得。コードはゼロから作成。
- IJV 設定（settings_ijv.go、新規）：主なメニュー、表示、VOX、サイドキー（V3 と V4）、
  16 グループと（V4、FW5）16 バンクの名前。
- UV-K5 ファームウェア（fwk5.go）：IJV バージョンの .bin ファイルは IJV タブを示し、警告を
  表示（V5・V6 は SYSTEM とモジュールも必要）。
- Windows のシリアルポート：DTR をオフにできる（SetDTR）。V6 のデータリンク用。
- カタログ：Quansheng UV-K5 と UV-K1 に IJV タブと IJV のサイトを追加。
- 翻訳：全言語に 143 件の新しいテキスト。
- テスト：IJV 無線機のシミュレーション（V3、V4、FW5、V6）、平文と純正プロトコル、FW5 の
  通知、バンク変更、書き込み拒否、校正データは書き込まないこと。
