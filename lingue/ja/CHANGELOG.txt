4.17.0（2026/11/11）
-------------------
- Kenwood TH-F6A、TH-F7E、TH-G71A/E、TH-D7A/E、TH-D7A(G)/E(G)、TH-K2（drv_kwlive.go、新規。CHIRP の kenwood_live.py と kenwood_d7.py ドライバーのコマンドを使用）：無線機は通常どおり電源を入れた状態、9600 ボー、1 チャンネルずつ。独自のイメージ形式。プログラムが変更しない項目は無線機が返したままです。周波数を変えないかぎりステップとモードは保持されます。書き込み時は無線機を読み直し、変更したチャンネルだけを送ります。模擬無線機でのみテスト済みです。
- Kenwood 業務用ハンディ機 60 シリーズ（drv_kwtk60.go、新規。CHIRP の tk270.py：TK-260、TK-270、TK-272、TK-278、TK-360、TK-370、TK-372、TK-378）と 60G シリーズ（CHIRP の tk760g.py：TK-260G、TK-270G、TK-272G、TK-278G、TK-360G、TK-370G、TK-372G、TK-378G、TK-388G）。CHIRP との意図的な違い：変更したチャンネルのビジーチャンネルロックアウト、beat shift、グループ、位置は元のままです。
- Radtel RT-860（カタログ）：Radtel のソフトは CHIRP の RT-880G ドライバーと同じコマンド、同じブロック、同じ 48 バイトのチャンネルを使うため、RT-860 はそのタブを使います（メーカーのソフトとの比較によるもので、実機では未確認）。
- カタログ：無線機 494、設定対応 425、ギャラリー 548、47 ブランド。設定：新しいクラス 17 件。翻訳：新しいテキスト 13 件。テスト：新しい Kenwood 3 ファミリーの模擬無線機、60 / 60G シリーズの CHIRP との比較。

4.13.1（2026/11/09）
-------------------
- IJV V6 ファームウェア（drv_ijv6.go、新規）：タブ「Quansheng UV-K5 V3 / UV-K1（IJV V6 ファームウェア）」。V6 のデータリンク（DTR と RTS は Low、CRC32 付きの「A5 5A」要求、12 バイトの「5A A5」応答）：情報とバージョン、予告した要求数でのオープン、256 バイト単位の読み込み、256 バイトのページを 4 KiB セクター単位で確定、終了と再起動。メモリは V5 と同じ（バンク n は 0x020000 + n·0x4000、現在のバンクは「CFG5」から取得し書き込み前に再読込）。変更されたセクターだけを書き、1 つずつ読み戻して比較します。校正データ、ライセンス、無線機が自分で管理する領域は無線機の内容のままです。
- 無線機が V6 のデータリンクにしか応答しない場合、ほかの IJV タブは V6 タブを案内します。
- 設定：V6 は V5 の表を使います。カタログと UV-K5 ファームウェア：V6 タブを追加。
- 翻訳：新規または変更されたテキスト 23 件。テスト：模擬 V6 無線機（読み込み、変更セクターのみの書き込み、バンク変更、設定の拒否、間違ったタブ）。

4.13.0（2026/11/09）
-------------------
- Quansheng UV-K5 / UV-K5 V3 / UV-K1 用 IJV ファームウェア（drv_ijv.go、新規）：4 つの
  タブ。200 チャンネルの V3（0x0500、8 KiB イメージ）、999 チャンネルの V3 X
  （0x2000-0x9FFF）、V4 と V5（無線機で選択したバンクの 500 チャンネル、24 KiB イメージ：
  固定領域 0x0000-0x1FFF とバンク 0x2000-0x5FFF）。32 バイトのチャンネルレコード。グループ、
  AGC、コンパンダー、スクランブラー、セレコール、TX ロック、ビジーロックは保持。接続：V3 は
  UV-K5 純正プロトコル、V4 と FW5 は IJV 平文プロトコル（応答がなければ純正プロトコル）、FW5 は
  物理読み書き（0x0564/0x0566）と最終保存（0x0576）。アクティブバンクはバイト 0x000B（V4）
  または「CFG5」（FW5）から取得し、書き込み前に再確認：無線機で別のバンクが選ばれていれば何も
  書き込みません。V4 と FW5 は変更ブロックのみ書き込み、校正データ（0x1E00 以降）、FW5 の設定と
  ライセンスは書き込みません。V6 はデータリンクで認識。形式は IJV が公開した CHIRP モジュール
  （3.60、V4.0、V5.0）と RadioManager 4.3.2 の解析から取得。コードはゼロから作成。
- IJV 設定（settings_ijv.go、新規）：主なメニュー、表示、VOX、サイドキー（V3 と V4）、
  16 グループと（V4、FW5）16 バンクの名前。
- UV-K5 ファームウェア（fwk5.go）：IJV バージョンの .bin ファイルは IJV タブを示し、警告を
  表示（V5・V6 は SYSTEM とモジュールも必要）。
- Windows のシリアルポート：DTR をオフにできる（SetDTR）。V6 のデータリンク用。
- カタログ：Quansheng UV-K5 と UV-K1 に IJV タブと IJV のサイトを追加。
- 翻訳：全言語に 143 件の新しいテキスト。
- テスト：IJV 無線機のシミュレーション（V3、V4、FW5、V6）、平文と純正プロトコル、FW5 の
  通知、バンク変更、書き込み拒否、校正データは書き込まないこと。
