QUANSHENG UV-K5 のファームウェア更新（4.1）
Quansheng の .bin ファイルの形式と UV-K5 のローダーのプロトコルは、フリーソフト k5prog（Copyright 2023 Jacek Lipkowski SQ5BPF、GNU GPL v3、https://github.com/sq5bpf/k5prog）と uvtools（egzumer、https://github.com/egzumer/uvtools）が記述しています。fwk5.go は相互運用のためにその記述をもとにゼロから書いたもので、それらのプログラムのコードはパッケージに含まれていません。試験専用の verifica/k5/k5ref.js は、検証する人が指定したフォルダーから uvtools のコードを読み込みます。SQ5BPF と egzumer に感謝します。

TIDRADIO TD-H3 / TD-H8 と RADTEL RT-730 のファームウェア更新（4.3）
ローダーのプロトコルは nicsure が TD-H3-Engineering プロジェクト（https://github.com/nicsure/TD-H3-Engineering、firmware_flash_protocol.txt、メーカーのプログラムのポートのキャプチャー付き）で記述し、彼のプログラム TID Station で使われています。同じ 36 バイトのハンドシェイクがメーカーのプログラム「H8_IAP」（TIDRADIO）と「RT730 Update tool」（Radtel）にもあります。fwtdh.go は相互運用のためにその記述をもとにゼロから書いたもので、それらのプログラムのコードはパッケージに含まれていません。nicsure に感謝します。

7.x ローダーによるファームウェア更新（UV-K5 V3、UV-K1、RA79 V3）（4.4）
このプロトコルはフリーソフト quansheng_toolkit（Copyright 2026 knoinok、Apache 2.0 ライセンス、https://github.com/knoinok/quansheng_toolkit、kradio/dfu.py）と Multi-UVTools（spm81、https://github.com/armel/Multi-UVTools、js/flash-k1.js）が記述し、使用しています。fwk5.go（k5v3Update）はその記述をもとにゼロから書いたもので、それらのプログラムのコードはパッケージに含まれていません。

RETEVIS RA89（4.4）と RT85（4.5）のファームウェア更新
プロトコルは相互運用のために Retevis のプログラム「RA89-update-software」（「TH8600-UpDAta Soft」2.3）と「RT85 10W_5W_UpData」（「TH8600-UpDAta Soft」2.1、retevis.com）から得ました。これらのプログラムはパッケージに含まれていません。試験専用の verifica/ra89 は、検証する人が指定した実行ファイルを読み込みます。

RADTEL RT-950 PRO、BAJETON BJ-9000、RADTEL RT-950（4.6、4.7）
4.7：Radtel RT-950PRO_CPS v1.2.1 と Bajeton BJ-9000_CPS v1.3.3（bajeton.cn）のプログラム、ローダー「RT-950_EnUPDATE」「BJ9000_EnUPDATE」「Radtel ANC Bootloader V1.2」（更新プロトコル、相互運用のため）とも比較しました。ファームウェア（Radtel radtels.com、Bajeton bajeton.com と bajeton.cn）は SHA-256 フィンガープリントでのみ識別します。プログラムやファームウェアはパッケージに含まれていません。
チャンネルのメモリーと設定は、相互運用のためにメーカーのプログラムのコード（Radtel RT-950PRO_CPS v1.1.1、v1.2.0、v1.2.1、v1.3.3 と RT-950_EnCPS「BT-9000_CPS」v1.3.0、radtels.com。Bajeton BJ-9000_CPS v1.1.1）と Radtel のファームウェアの説明から得ました。これらのプログラムはパッケージに含まれていません。JA van Hernen（PE1HVH）が RT-950 Pro 用の CHIRP ドライバーについて公開した説明（https://github.com/pe1hvh/chirp_radtel_rt950pro、MIT ライセンス。「F」コマンドへの無線機の応答はファームウェア 0.18 と 0.29 で同じ）と CHIRP の報告 12180 も参考にしましたが、それらのプロジェクトのコードは含まれていません。

NICFW ファームウェア（4.15）：nicFW は nicsure（https://nicsure.co.uk）によるものです。チャンネルのメモリー、設定、接続のコマンドは、相互運用のために作者が公開した資料（https://github.com/nicsure/nicfw2docs, https://github.com/nicsure/nicFW880_950_Docs）から得ています。nicsure のコード、プログラム、ファームウェアは一切含まれていません。drv_nicfw.go と settings_nicfw.go はゼロから書いたものです。独立したプログラムであり、nicsure とは無関係です。

OPENGD77 と UV-K5 のその他のファームウェア（4.16）：OpenGD77 は Roger Clark VK3KYY らによるものです。接続とメモリー構成は Hannes Matuschek DM3MAT のフリーソフト qdmr（GNU GPL v3）から得ています。kamilsss655 の NUNU ファームウェアと joaquim.org の UV-KX ファームウェア（Apache 2.0）：メモリーと書き込みは作者が公開した CHIRP 用ドライバー（Jacek Lipkowski SQ5BPF の uvk5.py から派生、GNU GPL v2 以降）と同じです。これらの作者のファームウェアやプログラムは一切含まれていません。drv_ogd77.go と drv_uvkx.go は IU0VYT Flash で書いたものです。独立したプログラムであり、彼らとは無関係です（https://www.opengd77.com, https://github.com/hmatuschek/qdmr, https://github.com/kamilsss655/uv-k5-firmware-custom, https://github.com/joaquimorg/UV-KX）。

KENWOOD TH-F6/F7、TH-G71、TH-D7、TH-K2 と TK ハンディ機（4.17）：drv_kwlive.go は CHIRP の kenwood_live.py と kenwood_d7.py ドライバー（Copyright 2010 Dan Smith）のコマンドを使います。drv_kwtk60.go と drv_kwtk_var.go は CHIRP の tk270.py と tk760g.py（Copyright 2016 Pavel Milanes CO7WT）から派生したものです（GNU GPL v3）。Radtel RT-860 のカタログ項目はメーカーのソフトとの比較によるもので、そのソフトは一切含まれていません。

KENWOOD TK-2140/3140、TK-280/380、R3B0RN ファームウェア、RADTEL RT-330 と RT-400（4.18）：drv_kwtk140.go は CHIRP の tk3140.py（Copyright 2023 Dan Smith）、drv_kwtk280.go は CHIRP の tk280.py（Copyright 2016 Pavel Milanes CO7WT, 2024 Dan Smith）に由来します（GNU GPL v3）。fagci の R3b0rn ファームウェア（https://github.com/fagci/uvk5-fagci-reborn、Apache 2.0 ライセンス、DualTachyon のファームウェアが基）：drv_fagci.go は、ファームウェアのソースコードに記述されたメモリー構成とコマンドをもとに IU0VYT Flash で書いたものです。作者のファームウェアやプログラムは一切含まれていません。独立したプログラムであり、作者とは無関係です。Radtel RT-330 と RT-400：メーカーのソフト（「Radio CPS」と「JJCC-7700 CPS」）との比較によるもので、その内容は一切含まれていません。チャンネルレコードは CHIRP の mml_jc8810.py のものです。R3b0rn ファームウェアを公開している fagci に感謝します。

ゾーン名（4.11）
ゾーン名の形式は、相互運用性のために、メーカーのプログラムのコードから得ました：Radtel RT-950PRO_CPS v1.2.0-v1.3.3 と Bajeton BJ-9000_CPS v1.3.3（RT-950 Pro、BJ-9000、HI-UV850 Pro）、RT-950_EnCPS「BT-9000_CPS」v1.3.0（RT-950）、RT-920_EnCPS v1.2.4（RT-920）、RT910_EnCPS v1.0.3（Bluetooth なしの RT-910）、radtels.com と bajeton.cn。RT-920 については CHIRP のドライバー radtel_rt900.py（Fred Trimble、GNU GPL、上記参照）からも得ました。メーカーのプログラムは含まれていません。
ゾーンに名前を付けるアイデアとチャンネルの一括編集は、Jorge De La Cruz KK4OXN の「RT-950 / 950 Pro Editor」プログラム（https://github.com/cruzerdlc/RT-950-950Pro-Editor、MIT ライセンス）から来ています。このリポジトリは文書とコンパイル済みのプログラムだけを公開しており、ソースコードはなく、そこからコードは取っていません。機能は IU0VYT Flash で一から書き直しました。

.BTU ファームウェア（4.8）
Bluetooth なしの Radtel RT-910 と RT-900、Bluetooth なしの Bajeton BJ-7700 の .BTU ファームウェアは、「Radtel Bootload Tools」プログラム（Radtel、radtels.com）のプロトコルで送ります。このプロトコルは相互運用のためにそのコードから得たもので、Baofeng UV-5RM の KDH V1.0 ローダー（bfkdh.go）と同じで、ハンドシェイクは「PROGRAMBT80U」です。ファームウェア（Radtel radtels.com、Bajeton bajeton.com）は SHA-256 フィンガープリントでのみ識別します。RT-900 ではメーカーのプログラム「RT900_512 CPS」v1.0.0 と v1.0.2（512 と 999 チャンネル）とも比較しました。プログラムやファームウェアはパッケージに含まれていません。

Radtel RT-470 / RT-495 / RT-630 の .kdhx ファームウェアは、UV-25 Plus の「Bootloader Pro」（fwkdhx.go）と同じプロトコルを使い、プラットフォームは Radtel のプログラム「New RT470 serial Bootloader Pro」が示す JJCC です。
CHIRP の元のファイルからの変更点（Go での書き直し、チャンネルのみ、IU0VYT Flash のインターフェースへの対応）は、各ファイルの先頭と CHANGELOG.txt に、各バージョンの日付とともに記載しています。

商標と相互運用性
----------------
IU0VYT Flash は独立したプログラムであり、Baofeng、Bajeton、その他記載のメーカー（例：Quansheng、Retevis、Radtel、Radioddity、TIDRADIO、Hiroyasu、Talkpod、Anysecu、BTECH、Abbree、MaxTalker、Intek、Maverick、WLN、Zastone、Luiton、Yaesu、Icom）とは提携しておらず、承認も受けていません。機種名は、このプログラムがどの無線機で動作するかを示すためだけに使っています。商標はそれぞれの所有者に帰属します。
データのプロトコルと形式は、無線機との相互運用のためにメーカーのプログラムから再構成しました（3.3 以降は「BF Series CPS」「T17-T18 PMR446 PRO / FRS」「DM-32UV CPS」と Bajeton の BJ-8200 のパッケージも。3.4 以降は「BF-Ts」「BAOFENG GT18 PMR」「BAJETON DM-5000 CPS」。3.5 以降は「DR-1801A6」とファームウェアのファミリー用の更新プログラム「Baofeng Bootloader Pro」「T6UV Series CPS」。3.6 以降は設定のための「GT-22」「BF_V1_FH」（GT-68）「BT-11_CPS」v1.0.8 と v1.0.9、「BJ-9000_CPS」「5RH PRO」。3.8 以降は BTECH DMR-6X2 の更新ファイルの構造。4.0 以降は CHIRP のドライバーが記述するほかのブランドの無線機のプロトコル）（イタリア法 633/1941 第 64 条の 4、指令 2009/24/EC 第 6 条）。パッケージにはメーカーのコード、プログラム、ファームウェアは含まれていません。機種のギャラリーはメーカーの公式サイトへ案内します。
