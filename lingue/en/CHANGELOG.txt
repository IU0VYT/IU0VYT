4.12.0 (09/11/2026)
-------------------
- Language at first start (i18n.go, syslang_windows.go): if the language has never
  been chosen with the flags, the program uses the first of the user's Windows display
  languages (GetUserPreferredUILanguages) that it has among its 11; if none, English.
  The choice made with the flags is saved and applies at restarts (now Italian is
  saved too: before, it was mistaken for «no choice»). The Windows message boxes
  follow the same language. Test: TestSysLang.
- Translations: «Yes» and «No» (Scan column and table menus) were too short for the
  list of texts to translate and stayed in Italian in all languages; the name of the
  license on the home page had stayed in Italian. Now they are translated (4905 texts
  per language).
- Security, CodeQL reports: bw.go writes the bytes of the words without truncating
  conversions; the data folder taken from the GESTIONE_CANALI_DIR variable (used by
  the tests) is cleaned and refused with «..»; firmware.js gets the plain text from
  the HTML with the browser instead of a regular expression;
  verifica/sito/brandcolors.js reads ui/gallery.js from the source folder and not from
  a path on the command line.
- Repository: README.md is now in English (main page of the repository), the Italian
  original is README.it.md; language bar with flags and pictures of the program in all
  READMEs; security policy (.github/SECURITY.md) in English with the translations in
  the other 10 languages (.github/security).
- Site: updated texts for identification, guide and license; preview picture for
  social networks (docs/img/social.png); flags and pictures of the program in
  docs/img; the pages are reported to Bing, Yandex and the other engines that use
  IndexNow at every publication.
