4.13.1 (09/11/2026)
-------------------
- IJV V6 firmware (drv_ijv6.go, new): tab «Quansheng UV-K5 V3 / UV-K1 (IJV V6
  firmware)». V6 data link (DTR and RTS low; «A5 5A» request with CRC32, 12-byte
  «5A A5» reply): info and version, opening with the announced number of requests,
  256-byte reads, 256-byte pages committed in 4 KiB sectors, end and reset. Same
  memory as V5 (bank n at 0x020000 + n·0x4000, active bank from «CFG5», read again
  before writing). Only the changed sectors are written, each read back and compared;
  calibration, licence and the areas the radio manages itself stay as on the radio.
- The other IJV tabs point to the V6 tab when the radio answers only the V6 data link.
- Settings: V6 uses the V5 table. Catalogue and UV-K5 firmware: V6 tab added.
- Translations: 23 new or changed texts. Tests: simulated V6 radio (read, write of the
  changed sectors only, changed bank, refused settings, wrong tab).

4.13.0 (09/11/2026)
-------------------
- IJV firmware for Quansheng UV-K5 / UV-K5 V3 / UV-K1 (drv_ijv.go, new): four tabs,
  «IJV V3 firmware, 200 channels» (channels at 0x0500, 8 KiB image), «V3 X, 999
  channels» (0x2000-0x9FFF), «IJV V4 firmware» and «IJV V5 firmware» (500 channels of
  the bank selected on the radio, 24 KiB image: fixed area 0x0000-0x1FFF and bank at
  0x2000-0x5FFF). 32-byte channel record; group, AGC, compander, scrambler, selective
  code, TX lock and busy lock are kept. Link: V3 with the UV-K5 factory protocol; V4
  and FW5 with the plain IJV protocol and, if the radio does not answer, the factory
  one; FW5 with physical read/write (0x0564/0x0566) and the final save (0x0576).
  Active bank from byte 0x000B (V4) or from the «CFG5» configuration (FW5): it is read
  again before writing and, if another bank is selected on the radio, nothing is
  written. V4 and FW5 write only the changed blocks; calibration (from 0x1E00), FW5
  configuration and licence never. V6 is recognised by its data link and the program
  explains that it is managed with IJV's RadioManager. Formats derived from the CHIRP
  modules published by IJV (3.60, V4.0, V5.0) and from the analysis of RadioManager
  4.3.2; code written from scratch.
- IJV settings (settings_ijv.go, new): main menus, display, VOX, side keys (V3 and
  V4), names of the 16 groups and (V4, FW5) of the 16 banks.
- UV-K5 firmware (fwk5.go): a .bin file with an IJV version points to the IJV tab for
  the channels, with a warning (V5 and V6 also need SYSTEM and modules, which only
  RadioManager loads).
- Windows serial port: DTR can be switched off (SetDTR), for the V6 data link.
- Catalogue: the IJV tabs in the Quansheng UV-K5 and UV-K1, with the IJV website.
- Translations: 143 new texts in all languages.
- Tests: simulated IJV radios (V3, V4, FW5, V6), plain and factory protocol, FW5
  announcements, changed bank, refused write, calibration never written.
