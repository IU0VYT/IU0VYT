启动
- 双击“IU0VYT Flash.exe”。会打开主界面“🏠 Home”，顶部有固定的标签页“🏠 Home”“📻 型号”“中继台档案”和“ℹ Info”；从型号库中选择的每一款电台（包括 Baofeng K67 Pro 和 Bajeton 8300）都会在新的标签页中打开，点 × 关闭。
- 从 2.x 版升级时，只需替换可执行文件：档案、设置和副本都保持原位。
- 从 2.1 或更早版本（GestioneCanali.exe）升级时：中继台档案、设置和副本保持不变（文件夹 %APPDATA%\GestioneCanaliRadio）；旧的 GestioneCanali.exe 可以删除。
- 本程序没有数字签名：首次启动时 Windows 可能显示“Windows 已保护你的电脑”。点击“更多信息”，再点击“仍要运行”。
- 窗口使用 Windows 11 自带的 WebView2 组件。如果缺少该组件，程序会在默认浏览器中打开，并有一个小窗口用于关闭程序。
- 同一时间只能打开一个程序副本。

使用方法
使用写频线：
1. “📻 从电台读取…”：电台的信道显示在表格中。
2. 修改信道；也可保存到文件（另存为…）作为副本。
3. “📻 写入电台…”。
使用文件（与 1.0 版相同）：
- 打开用原厂程序或本程序保存的 .xlc 文件（K67 Pro）或 .dat 文件（Bajeton 8300），修改后保存（Ctrl+S）。在这里保存的文件也可以用原厂程序打开和写入。
覆盖已有文件保存时，旧版本会以 .bak 扩展名保留在旁边（例如 k67.xlc.bak）。

型号库
- “📻 型号”标签页显示所有 Baofeng 电台（baofengradio.com 的产品目录和下载页面）、Bajeton 电台（bajeton.com），以及从 4.0 起支持的其他品牌（Quansheng、Retevis、Radtel、Radioddity、TIDRADIO、MaxTalker、Abbree、Intek、Maverick、BTECH、WLN、Zastone、Luiton、TID，以及从 4.1 起的 Hiroyasu、Talkpod、Anysecu）。可按品牌或名称（包括别名，例如 UV-5RA、MINI-5、GT-3TP、UV-K5）搜索，并按品牌（“所有品牌”菜单）、类型（业余无线电、DMR、GMRS / FRS、PMR446 及免执照、儿童）、支持数据线写信道或支持固件的电台筛选。
- 上方是本程序支持的“兼容型号：N”（标签“信道”和“固件”），下方是“不兼容型号：N”，这些型号只能用厂家程序或自由软件写频：为它们提供了程序、固件和说明书的官方链接。N 为型号数量（使用搜索和筛选时为显示的数量）。从 4.3 起，两部分之间有一条粗线分隔。
- 每部分中的电台按类型划分：业余无线电（VHF/UHF）、DMR（数字）、GMRS / FRS（美国）、PMR446 及免执照电台、儿童；每个类别中的电台再按品牌分开（先 Baofeng，后 Bajeton，其他按字母顺序，并显示每个品牌的型号数量），型号按字母顺序排列（UV-5R 在 UV-17 之前）。每款电台的卡片上标有品牌，每个品牌有自己的颜色（Baofeng 蓝色、Bajeton 橙色、Quansheng 绿色、Retevis 红色、Radtel 紫色……）。

电台设置（3.6）
- 通过数据线读取电台或打开它的文件后，电台标签页中的“⚙ 设置…”按钮。左侧是分组（例如“接收与发射”“显示、声音和按键”“DTMF”），上方是搜索。每一项都有：
    ⓘ  该项的说明（鼠标悬停时显示；单击后在下方保持展开）；
    ⚠  在敏感项上：警告写在说明中，应用之前会有窗口汇总警告并要求确认。
  已更改的项会突出显示；“应用”把它们写入标签页的存储（标签页变为“已修改”）：然后像信道一样保存文件或写入电台。“撤销更改”恢复读取时的值。
- 敏感项：密码（开机、读取、写入）、各频段的频率限制和发射允许、禁止发射、最长发射时间、VOX、复位和菜单项、PTT-ID 和发射的代码、会发射的报警、中继功能、遥毙、蓝牙编程、键盘锁。
- K67 Pro / 5RH Pro（53 项）：来自“5RH PRO”程序的 ConvertSetting 和 SettingConvert 方法。
- Bajeton BJ-8300（40 项；在 BT-11_CPS v1.0.9 的文件中为 41 项，多了“信道划分”）：程序的“Optional Features”窗口；每一项都是 .dat 文件中所保存对象的一个数字，就地修改（文件与该程序保存的文件保持一致）。
- Bajeton BJ-9000、Radtel RT-950 Pro 和 RT-950（57 项）：厂家程序的“Optional Features”窗口；只修改每一项的位，其他字节保持电台中的值。各频段的活动区域为 10 或 15 个，取决于固件版本。

- Baofeng RD-5R 和 DM-1801（4.10，31 项）：按 qdmr 描述的 Radioddity GD-77 系列常规设置（DMR 名称和 ID 与 dmrconfig 相同）；不改动密码。Baofeng DM-1701（4.10）：名称、DMR ID 和开机文字，这是 dmrconfig 与 qdmr 一致的仅有字段。
- 尚不可用：D 系列、T17 / T18、GT-18、T9、GT-22、GT-68、BF-C2、BF-88ST、BF-9700 / BF-S56 Max、DM-5000、DR-1801UV，以及 CHIRP 未列出的 UV-17 Pro 系列型号（UV-25 Plus、AR-152 Pro、UV-29 Pro、UV-28 Pro、UV-7B、UV-17R、UV-21R、UV-21L）：这些电台请使用厂家程序。

- Retevis RT85（4.5）：Retevis 的 .hex 文件（例如“RT85-Firmware-V1.53.hex”）。Retevis 程序“RT85 10W_5W_UpData”（“TH8600-UpDAta Soft”2.1）的协议，与 RA89 相同但暂停更短：程序从 .hex 文件（不是明文固件：它是加密的）准备包含 4 行数据（64 字节）及其校验和的块；1.53 文件共 1024 块。原始代码已在模拟电台上运行：块和命令逐字节一致，57600 和 115200 波特，5 W 和 10 W，电台报错时也一致。
- RT85，Retevis 的步骤：电台关机，按住 PTT 和 P1 开机：指示灯变绿。连接数据线，选择电台的功率，然后点击“开始升级”。功率的选择与 Retevis 程序相同（“5W”或“10W”）：电台只响应自己型号的握手，否则程序会立即停止，不写入任何内容（此时请尝试另一个选项）。Retevis 网站上介绍的 RT85 是 5 W 版本（与 TYT TH-UV88 相同）。还必须输入 RT85 进行确认。
- RT85，注意（Retevis）：如果升级中断，不要开机（微控制器会永久锁死）：让它保持在升级模式并立即重新升级。
- Retevis 固件可从 retevis.com 下载（Firmware 页面）。型号库中其他 Retevis 电台没有 Retevis 发布的固件。

BAOFENG 固件升级
- Baofeng UV-5RM / UV-5RH（带“330L”TFT 显示屏的系列），.BF 文件：厂家程序“BF Upgrade Tool for TFT 330L Series”（KDH V1.0 引导程序）的协议。两种模式，与原程序相同：自动（电台开机：被切换到引导程序；之前可选择保存其信道的备份）和手动（按住 PTT 开机，屏幕熄灭：也适用于无法启动的电台）。注意：存在使用不同射频芯片（BK4819、AT1846S、FD6818）的版本，固件不能互换；文件名通常会注明（例如 5RH_BK_V0.14_231123.BF）。程序会检查文件（文件头、区域、有效的 ARM 程序、加密部分一致），并识别社区收集的固件（SHA-256 指纹）；Baofeng 没有在其网站上发布这些固件。
- Baofeng 5RH Pro（以及使用同一“5RH_PRO”CPS 的电台，如 K67 Pro），“BF_5RH”.dat 文件：厂家升级程序（Radio.exe）的协议。电台必须按厂家说明进入升级模式；开始时它会声明自己的电路板（V1 = 固件 1.x，V2 = 固件 2.x），如果与文件不符，升级不会开始。存储被擦除后就不能再中断。
- Bajeton BJ-7800：与 BJ-8300 相同的程序（“BinTe ANC Bootloader”）和相同的 .anc 文件（官方固件 BJ7800_CN_EN_V0.17_20251126.anc，位于厂家的 Google Drive）；型号由文件名识别。升级前的备份是 .img 文件（BJ-7800 驱动）。
- 从 3.1 起，使用官方升级程序的协议（“KDH_Bootloader”类，由其代码得出）：
    UV-25 Plus，.kdhx 文件（“Baofeng Bootloader Pro”；官方 V0.23，2025/05/22）；
    UV-9G，.kdh 文件（“Bootloader_BaudRate38400”，用于在信道 15 发射的升级；官方 T52GMRS_M8_V02_231004.kdh）；
    Bajeton BJ-9000，.Firmware 文件（“BJ9000_EnUPDATE”；官方 V0.27，2026/03/13；电台还会检查文件中写入的型号）。
  自动模式（电台开机）或手动模式（按厂家指定、窗口中显示的按键开机：UV-25 Plus 为 SK2+SK3，UV-9G 为 12+13 键，BJ-9000 为侧键 3+4）。文件会被检查（有效的 ARM 程序、文件名中的型号、官方固件的 SHA-256 指纹）。
- 带蓝牙的 Bajeton BJ-7700：与 BJ-8300/BJ-7800 一样的 .anc 文件（官方 BJ7700PRO_V0.06_251124.anc）；用 BJ-7700 的协议识别电台，备份为 .img 文件。
- BJ-8200（3.3）：固件和程序与带蓝牙的 BJ-7700 相同。
- 从 3.5 起，同一系列的电台使用相同的引导程序（协议已在上文用原始代码验证；只是目标电台不同）：
    .BF 文件（UV-5RM 的 KDH V1.0 引导程序）：K5 Plus、UV-5RM Plus、UV-17R、UV-17R Plus、UV-21R、UV-21L、UV-21、BF-T60 / TR-988UV。这些电台属于“T6UV Series CPS”程序，该程序也支持 UV-5RH（在 CHIRP 中 K5 Plus 和 UV-5RM Plus 源自 UV-5RM）；
    .kdhx 文件（“Bootloader Pro”引导程序，平台代码 H802）：UV-28 Pro、UV-29 Pro / SW-9、AR-152 Pro、UV-7B、UV-32。它们使用与 UV-25 Plus 相同的厂家程序（“BF-UVs Pro CPS”）；“Bootloader Pro”引导程序为“BF_H802”平台编写，与“T6UV Series CPS”的内部名称相同：对这些电台，窗口也接受 .kdhx 文件。
  Baofeng 只为 UV-25 Plus 和 UV-9G 发布固件：其他电台需要厂家或经销商提供的文件。目标型号由文件名识别（例如“UV29Pro_…kdhx”“K5Plus_…BF”）：如果不是当前标签页的电台会出现警告；如果不是 UV-25 Plus（.kdhx 文件）或 UV-5RM / UV-5RH（.BF 文件），必须输入型号才能开始升级（例如 UV29PRO、K5PLUS；文件名未注明时输入 H802）。当窗口中选择的电台与文件不符时，也需要书面确认。已知文件（SHA-256 指纹）比文件名更可靠：重命名后的 UV-25 Plus 官方固件仍然是“用于 UV-25 Plus”。在自动模式下，不响应升级请求的电台不会被修改。
- DM-32UV、DM-5000、M20D：只能用厂家程序升级（型号库中有链接）。DM-32UV 的升级功能在厂家的原生程序中（无法以可验证的方式从代码得出协议），M20D 和 DM-5000 使用加壳或被杀毒软件标记的程序。没有与原始代码比对，错误的升级可能使电台无法使用：因此不支持。无蓝牙的 BJ-7700（.BTU 文件）从 4.8 起可以升级，RD-5R、DM-1801 和 DM-1701 从 4.10 起可以升级（见上文）。

通过数据线读取和写入
- 连接数据线，打开电台，在窗口中选择数据线的 COM 端口（驱动名称有助于识别，例如“USB-SERIAL CH340 (COM3)”）。如果没有出现端口，请安装数据线驱动并点击“刷新”。
- 协议与厂家原程序（K67 Pro 的 CPS、5RH_PRO 和 Bajeton 的 BT-11_CPS）相同，由其代码得出：相同的命令、相同的加密、相同的检查、相同的暂停。
    K67 Pro：19200 波特（电台可能会自行要求 115200，与原程序相同），可选的编程密码（最多 8 个字符）。
    Bajeton 8300：57600 波特。
- 默认情况下，写入前程序会读取电台并保存备份；写入后会重新读取电台并比对信道。如果电台在写入结束时重启，回读会等待并重试，直到电台再次响应（最长 45 秒，3.9.2）。
  备份和读取结果位于 %APPDATA%\GestioneCanaliRadio\copie_radio（可以像普通 .xlc/.dat 文件一样打开）。如果备份失败，则不写入任何内容。
- 与原程序一样写入整个存储：除信道外，还会写入你正在处理的文件或读取结果中的常规设置（菜单、VFO、区域、DTMF……）。若不想更改它们，请从电台的读取结果开始。在 K67 上，前 128 字节（电台数据、型号、频段）永远不会被覆盖：程序像原程序一样从电台读取它们。
- 写入前的检查（与原程序相同）：K67 的频段与文件不同，或“BF-K6”型号未先读取 → 拒绝写入；无法转换的数据 → 在连接电台前报错。
- 读取和备份可以中断；写入不能中断（电台会留下不完整的数据）。如果写入中断（拔掉数据线、电台关机），请重新写入：备份位于上述文件夹中。
- 读取后，信道显示为“尚未保存到文件”。
- 电台连接电脑时，不要同时使用原程序（COM 端口只能由一个程序打开）。

固件升级（BAJETON 8300）
在“Bajeton 8300”标签页中点击“⬆ 升级固件…”。窗口分三步。
1. 固件
   - “电脑上的文件…”：选择固件文件（.anc，例如 BJ8300_V0.12_20251112.anc），或包含它的 .zip 或 .rar 压缩包，嵌套的压缩包也可以（如厂家的软件包：.rar 中有一个 .zip，里面是 .anc）。
   - “从互联网”：粘贴文件地址（.anc、.zip 或 .rar）并点击“下载”。Google Drive 和 Dropbox 单个文件的分享链接也可以使用。Google Drive 文件夹的链接无法下载：请在浏览器中打开文件夹并复制文件的链接，或者下载后从电脑加载。下载的固件保存在 %APPDATA%\GestioneCanaliRadio\firmware。
   - 如果压缩包中有多个固件，程序会询问使用哪一个。
   - 对文件的检查：格式（电台固件的“JLUFW”签名）、解密（.anc 文件是加密的：程序像原程序一样解密并检查内容可读）、平台与 BJ-8300 官方固件一致（YHD15C8_soundbox）、文件名、已知官方固件的 SHA-256 指纹。2025/11/12 的 BJ8300 V0.12 固件（Bajeton 最新发布的版本）被识别为官方固件。无效文件不能发送；有提示的文件（例如平台不同）需要额外确认。
2. 电台
   - 选择数据线端口和电台状态：
     “工作正常”（相当于原程序的“Update”按钮）：首先用 Bajeton 8300 的编程协议（与“从电台读取”相同）识别电台，并默认读取和保存其信道和设置的备份（copie_radio 中的 Bajeton_prima_del_firmware_….dat）。如果电台的响应不像 Bajeton 8300，升级不会开始，电台不受影响。然后电台被切换到升级模式并接收固件。
       “识别电台”只做检查，不升级。
     “无法启动”（恢复模式，相当于“Click Here If Your Radio Can't Work”按钮）：用于没有有效固件的电台。电台无法被识别：程序与原程序一样等待约 12 秒，让电台以升级模式出现。点击“开始升级”，并立即按经销商的说明让电台进入升级模式（通常是按住某个键开机，常为 PTT：此步骤没有文档说明）。
   - 传输速率：115200 波特（原程序默认）或 57600。
3. 确认
   - 必须勾选“我确认连接的电台是 Bajeton BJ-8300”。
   - 当程序未识别电台时（恢复模式，或“跳过自动识别”），还必须在框中输入 BJ8300。
升级过程中，窗口会显示进度和消息。不要关闭电台，也不要拔掉数据线；请使用充满电的电池。只有在电台开始响应之前才能中断操作。完成后关闭再打开电台，并在开机时检查版本；如果信道或设置发生了变化，请把升级前保存的备份写入电台。如果升级中断：关闭再打开电台并重试；如果电台无法再启动，请在恢复模式下重试。
协议：厂家程序“BinTe ANC Bootloader”V1.1（BinTalk）的协议，由其代码得出：AA 55 数据包带 CRC16，9600 波特，进入升级模式的命令，切换到 10000 波特，然后切换到所选速率，发送电台请求的数据，间隔 2 秒重试 5 次。原程序既不检查文件也不检查电台型号：上述检查由本程序增加。
.rar 压缩包（RAR 1.5-5 格式，包括“固实”压缩包）由程序使用自由解码器 rardecode（BSD 许可证）打开。不支持带密码的压缩包和分卷压缩包。

信道表
- 双击、Enter 或 F2 编辑单元格；也可以直接开始输入。Esc 取消编辑。在空行上从输入接收频率开始。
- 频率单位为 MHz（145.600 或 145,600）。频差写作 -0.6、+1.6、+5：发射频率会自动计算。若发射频率在另一个频段，请直接输入发射频率。
- 亚音：标准 CTCSS 亚音（67.0 … 254.1）或 DCS 码：D023N 正常，D023I 反向（D023 = 正常）；空白 = OFF。“发射亚音”用于打开中继台，“接收亚音”是接收时的亚音静噪。K67 接受任意八进制 DCS 码；Bajeton 接受 104 个标准码（D023 … D754）。
- 扫描：信道是否加入扫描（现在 K67 也支持）。
- 模式（仅限有数字信道的电台）：模拟或 DMR / 数字。数字信道不使用亚音，保留电台的数字设置。
- 选择：单击，Shift+单击（范围），Ctrl+单击（添加），Ctrl+A（全部）。
- 勾选（3.9.3）：每个信道左侧的复选框（Shift+单击勾选一个范围，空格键勾选选中的行）；列标题中的复选框勾选可见信道，“☑ 全选”/“☐ 全不选”作用于电台的全部信道。“📻 转发到其他电台”和“→ 档案”使用勾选的信道，如果没有勾选则使用选中的信道。移动或编辑信道时勾选会跟随信道；勾选不会保存到文件中。
- 按钮和按键：添加；插入行（Ins）；清除（Del）；删除并压缩（Shift+Del）；上移/下移（Alt+↑ / Alt+↓）；排序（按频率、名称、亚音：如果选中了多个信道，只对这些信道排序）；压缩（去除空位）；复制/剪切/粘贴（Ctrl+C/X/V）；撤销/重做（Ctrl+Z/Y）。在表格上右击会打开包含相同操作的菜单。
- 粘贴到已占用的位置时，程序会询问是覆盖、向下移动插入，还是只使用空闲位置。
- Bajeton 8300：15 个区域，每区 64 个信道。在表格上方的栏中选择区域，“全部”可同时查看；“移到区域”会移动选中的信道。
- K67 Pro：640 个信道。电台的频段从文件中读取：超出范围的频率以红色突出显示。
- 批量修改（4.11）：“✎ 批量修改…”（也可从右键菜单打开）可同时修改已勾选的信道，没有勾选时则修改已选中的信道：功率、带宽、扫描、TX 亚音、RX 亚音（OFF 表示去掉亚音）、频差，以及在电台允许时的发射（仅接收）。保持“不修改”的项目在每个信道中保持原样；数字信道不设置亚音。修改任何信道之前先检查亚音和频差；Ctrl+Z 撤销整个操作。

区域名称（4.11）
可以给每个区域命名，代替“区域 1”“区域 2”……，与厂家程序相同。“✎ 区域名称…”按钮（或双击区域栏中的某个区域）打开带名称的区域列表；区域栏和底部状态行显示“编号 · 名称”。名称保存在电台的存储器中：与信道一起通过数据线读取和写入，并保存在 .img 文件中。
- Radtel RT-950 Pro、Bajeton BJ-9000、Hiroyasu HI-UV850 Pro（固件 0.23 及更早：15 个区域；0.24 起：10 个区域）和 Radtel RT-950（15 个区域）：最多 12 个字符；不带重音的字母、数字、符号和汉字（GB2312，每个 2 字节），与厂家程序 RT-950PRO_CPS v1.2.0-v1.3.3、BJ-9000_CPS v1.3.3 和 BT-9000_CPS v1.3.0 相同（区域 0xC000，每个区域 16 字节）。
- Radtel RT-920（固件 V0.17 及更高版本，10 个区域）：最多 10 个字符，与 CHIRP 的驱动程序相同（厂家程序 v1.2.4 允许 12 个；区域 0xC800）。
- 无蓝牙的 Radtel RT-910 / Bajeton BJ-7700（15 个区域）：最多 12 个不带重音的字符，与厂家程序 RT910_EnCPS v1.0.3 相同（区域 0xA200）。
- DMR 电台 Baofeng RD-5R、DM-1801 和 DM-32UV：重命名已有的区域（最多 16 个字符）；每个区域都必须有名称。
- 安全：对于 RT-950 Pro、BJ-9000、HI-UV850 Pro、RT-950 和 RT-910，只有名称改变时才写入名称区域，并且写入前先从电台重新读取：如果其中的数据不是名称（固件没有区域名称），则不写入任何内容并显示提示。空名称使该区域保持电台显示的样子。对于 RT-920，该区域属于每次都写入的区域，与 CHIRP 的做法相同。
- 4.11 之前为 RT-950 保存的 .img 文件不包含名称：请重新读取电台以查看名称。如果电台不响应名称的读取（旧固件），文件中就没有名称，其他一切照常工作。

两台电台之间的复制
在第一个标签页中复制，在另一个标签页中粘贴（从 3.9.3 起“复制到…”改为“📻 转发到其他电台”，直接写入连接的电台：见“转发到其他电台”），会按照转换器的逻辑调整信道并显示警告：
- 名称：K67 最多 16 个字符，Bajeton 最多 12 个（保留缩写 M. S. D. 和末尾的数字，例如“CAMPOLUNGHINO 3”→“CAMPOLUNGH 3”）；
- 功率：Bajeton 的中功率在 K67 上变为高功率；
- DCS 亚音：如果目标电台有该代码则转移，否则设为 OFF 并给出警告；
- 超出 K67 频段的频率。
在插入窗口中选择区域（Bajeton）、起始位置，以及是只使用空闲位置还是覆盖。

转发到其他电台（3.9.3）
“📻 转发到其他电台”（在每个电台的标签页和右键菜单中）会把选择的信道直接写入另一台用数据线连接的电台：
1）勾选信道（左侧复选框；“☑ 全选”选择电台的全部信道）：如果没有勾选，则使用单击选中的信道；
2）在两个下拉菜单中选择目标电台的品牌和型号（型号按类型分组），以及信道放在哪里：放在空闲位置（电台中已有的信道保留），或替换电台的全部信道；
3）确认型号正确，且电台已连接数据线并已开机；
4）兼容性检查，与中继台档案相同：频率在电台的频段内，PMR446 / GMRS 设备上不放业余无线电信道（如果电台仍接受这些频率则显示黄色警告），纯模拟电台上不放 DMR 信道。你可以取消、选择其他电台或只发送兼容的信道；
5）选择数据线端口并点击“转发并写入”。程序会读取电台并保存备份（“copie_radio”文件夹，文件名“..._prima_dell_inoltro_...”），按电台调整信道（名称、字符、亚音、功率、仅接收或数字信道、锁定的位置如固定的 GMRS 信道），写入后重新读取电台进行验证。
电台的设置（菜单、VFO、按键……）保持从电台读取的值：只改变信道。如果空闲位置不足或没有可用的信道，程序会在写入前停止，不向电台写入任何内容。完成后，窗口会显示使用的位置和所做的调整；如果目标电台的标签页没有打开，“显示电台的信道”会打开它，并显示电台中当前的信道。

保留的内容
程序只修改你更改的内容。打开后不做修改就保存的文件逐字节保持一致。程序不解析的数据（K67 记录的其他字节、Bajeton 的信令/PTT ID/繁忙锁定等字段）保持不变，并在同一电台内移动或复制信道时随信道一起移动。电台的常规设置只能通过“⚙ 设置…”更改（且只更改你修改的项）。K67：添加或删除信道时，区域列表、A/B 信道和紧急信道会像原程序一样更新（区域不能在这里编辑）。

1.0 版错误的修正（K67 Pro）
分析原程序时发现，.xlc 文件每个信道有两个位表（“位置已占用”和“加入扫描”）。1.0 版使用了错误的位表：添加到原本为空的位置的信道，可能对电台和原程序不可见（修改和删除已有信道则是正确的）。如果你用 1.0 版保存过 .xlc 文件，并在空位置添加了信道，请用本版本打开：程序会指出受影响的位置，只需重新插入这些信道（或重新添加）即可。

中继台档案
- 所有电台共用，并自动保存在电脑上：%APPDATA%\GestioneCanaliRadio\archivio_ponti.json（备份：.bak）
- “导入…”：从互联网（预设地址 https://www.ik2ane.it/pontixls.xls，可修改；用过的地址会被记住）或从 .xls、.xlsx、.csv 文件导入。可识别 IK2ANE 的列表（“ponti”工作表）、CHIRP 的 CSV、本程序导出的文件，以及带有频率、频差、亚音、名称、地点、地区、省份、类型、网络等表头的普通表格。
- 不规范的值会按常理解释并加以提示（带 ⚠ 的黄色行）：
    "+5.0MHz", "-600 kHz"         → 普通频差
    "+1.362,5 MHz"                → 1.3625 MHz（提示）
    "79,7" "123"                  → 79.7 / 123.0
    "77.0-141.3" "110.9/162.2 loc"→ 使用第一个亚音，其他的在警告中列出
    "82.2"（非标准）               → 82.5，提示
    "CC1"（DMR 色码）              → 无亚音，记入备注
    "DCS023", "1750", "DG-ID:10"  → 记录/提示
    "input" / "output"            → 同频，提示
  原始值在详情面板中仍然可见。没有有效频率的行（例如占位值 9999999 和末尾的文字行）不能导入：它们会在窗口中列出，而不是悄悄丢弃。
- 也会读取 IK2ANE 文件中图例的颜色：已停用的中继台、暂时停用、非 24 小时、非本地区亚音、非标准频差。
- 筛选（在导入、导出和档案中）：频段（VHF/UHF/其他）、类型（模拟、EchoLink、SvxLink、DMR、C4FM、D-Star、NXDN、多模、HotSpot、转发器、Winlink）、状态、地区、省份、网络、自由文本、仅显示有警告的行；另外还有逐行勾选。导入时筛选默认为“仅限可用于模拟的中继台，不含已停用的”：可以更改。
- 信道名称：可自选模板，使用 {LOC} {SIGLA} {NOMINATIVO} {PROV}（地点、代号、呼号、省份；例如“{NOMINATIVO} {LOC}”→“IR0XX M.ALTO”）。“重新生成名称…”会重新应用模板。
- 已存在的中继台（频率、发射频率、地点和代号相同）：可以只添加新的、更新已有的（你起的名称保留），或全部替换。
- 勾选要放入电台的中继台：每行左侧的复选框（空格键勾选选中的行），或“☑ 全选”和“☐ 全不选”，它们作用于当前筛选下可见的中继台。勾选会保存在档案中，关闭程序后仍然保留。
- “📻 转发到电台”把勾选的中继台写入电台（如果没有勾选，则使用单击选中的）：
    · 如果已经选定了电台（蓝色“目标电台”栏中显示的电台，即最后使用的或最后打开的电台标签页），会出现一个显示型号并请求确认的窗口（“确认并写入”，或“选择其他电台…”）；
    · 否则会打开所有兼容电台的列表，带有搜索：按品牌（Baofeng、Bajeton）和类型分组，每个型号单独按字母顺序列出（括号中为使用的驱动，例如“UV-5RA（驱动：Baofeng UV-5R）”，或在电台有多个版本时显示版本）。
  写入前，程序会检查中继台是否与所选电台兼容：
    · 接收和发射频率在电台的频段内；
    · PMR446 / 免执照设备（仅 446.0-446.2 MHz）或 GMRS / FRS 设备（仅 462.55-467.725 MHz）上不放业余中继台；
    · 纯模拟电台上不放纯数字中继台（DMR、C4FM、D-Star、NXDN）；在 DMR 电台（DM-32UV、DM-1801 Pro、DM-5000）上，纯 DMR 中继台会变成 DMR 信道。
  例外：一些作为 PMR446 / 免执照或 GMRS 销售的电台也接受业余频率（驱动的频段与厂家程序相同，例如 BF-T17 PMR446 为 400-480 MHz）。对于这些频段内的中继台，会出现带有“仍然写入这 N 个中继台”的黄色警告：允许写入（也可以在电台标签页中粘贴或插入中继台）。请遵守法规：在业余频率上发射需要执照，经认证的 PMR446 设备不得在其信道之外使用。
  如果没有问题，中继台就会被发送；否则会出现警告（“你选择的设备与你要发送到电台的数据不兼容”）并列出问题，电台中不会写入任何内容：你可以取消、选择其他电台，或在部分中继台兼容时只发送这一部分。
  然后会打开常规的插入窗口（起始位置、只用空闲位置或覆盖、针对电台的调整）；如果电台尚未读取，程序会建议通过数据线读取或打开它的文件。蓝色栏中的“更换电台…”可以更改目标。
- “复制”复制勾选的（或选中的）中继台，以便粘贴到电台中（Ctrl+V）。
- “🗑 删除”（3.9.3）从档案中删除勾选的中继台，包括被筛选隐藏的（确认时会说明数量），如果没有勾选，则删除单击选中的；Del 键删除选中的行。“🗑 全部删除”清空档案。两者都会要求确认，只要程序保持打开，就可以用 ↶（Ctrl+Z）撤销；要重新加载 IK2ANE 的列表，请使用“⬇ 导入…”。
- “标记为已核实”在检查后移除警告（警告保留在备注中）。

转换器和通用格式（3.7）
- “🔁 转换”标签页：1）选择源文件或已打开的标签页；2）选择目标格式（按名称搜索）；3）“转换并保存…”。转换后，列表会显示所有调整（缩短的名称、功率、不可用的亚音、超出频段或被排除的信道），“在电台标签页中打开”会打开生成的文件。
- 源文件：.xlc（K67）、.dat（Bajeton，v1.0.8 或 v1.0.9）、任何兼容电台的 .img 映像（包括 CHIRP 保存的：根据文件数据识别型号）、CHIRP 的 CSV（包括带注释行的）、Excel 或 CSV 表格（从这里或中继台档案导出，或手工编写：需要一列频率，例如“RX (MHz)”“Frequenza”或“Frequency”；名称、发射频率、频差、亚音、功率、带宽、扫描、仅接收、数字为可选）。
- 目标格式：CHIRP 的 CSV（通用格式，可用 CHIRP 为任何电台打开）、Excel .xlsx、Excel 用 CSV、K67 的 .xlc 文件、BT-11_CPS v1.0.8 或 v1.0.9 用的 Bajeton .dat 文件、每款驱动支持电台的 .img 映像。如果电台有相同的位置，信道保持在原位置（或“压缩信道”）；多出的信道放到最前面的空闲位置，其余的被排除并提示。某些电台的锁定位置（例如 GM-15 Pro 的固定 GMRS 信道）保持电台原有的设置。
- 要生成某个电台的 .img 映像，需要同一台电台的映像，即其存储的完整副本（“从电台读取”或“打开…”后打开的标签页，或之前从这里或 CHIRP 保存的 .img 文件；从 3.8 起也可以直接在转换器中用“📻 立即读取连接的电台…”）：映像包含电台的设置和校准，这些无法凭空生成，写入“空”映像会损坏电台。对于 K67 和 Bajeton，也可以从厂家程序的默认设置开始。
- “📥 导入…”（每个电台的标签页中）和“导出…”→“🔁 用于其他电台…”使用同一个转换器。

电台识别（3.8）
- “🔎 识别”标签页：选择数据线端口（或对于直接使用 USB 线的 DMR 电台选择“USB”：RD-5R、DM-1801、DM-1701），然后点击“识别电台”。可以按品牌或类型（模拟 / DMR）缩小搜索范围：这样更快。
- 程序会依次尝试各种读取协议（先 K67 Pro 和 Bajeton BJ-8300，再是驱动支持的电台，从已打开标签页的电台开始）。以相同方式开始连接的型号只尝试一次（通过数据线的 100 款电台共 38 次尝试；从 4.1 起，通过数据线的所有电台共 60 次尝试）。当某台电台响应时，会像“从电台读取”一样被完整读取，读取结果的副本保存在备份文件夹（copie_radio）中。
- 型号通过存储内容识别，就像 CHIRP 识别文件一样。但许多电台使用相同的协议和存储，却没有在任何地方写入自己的名称（例如 UV-17Pro 系列电台、BF-888S 系列的 PMR 电台）：这时程序会说明（“无法通过数据线区分型号”），并在打开信道前让你选择正确的型号。
- 显示内容：品牌和型号、类型（模拟 FM 或 DMR、PMR446、GMRS）、频段、存储数量、使用的连接、电台报告的固件或标识（例如 UV-5R“BFB297”、BJ-8300“BT-11U V1.00”、DM-32UV 的固件、K67“5RH-PRO”或“BF-K6”）、连接时电台发送的文本、现有信道；对于 RD-5R、DM-1801 和 DM-1701 还有 DMR ID、电台名称、最近编程的日期以及（DM-1701）写入它的程序版本。序列号：这些电台都不会通过编程协议报告序列号（只印在标签上）。
- “在电台标签页中打开信道”：与“从电台读取”之后相同。
- 用时（4.3）：没有连接电台时，完整搜索约需 50 秒（81 次尝试；按品牌或类型缩小范围时会更少）；先尝试过去识别过的电台（最近 24 台），再尝试已打开标签页的电台，然后是其他电台。响应的电台一轮到就会被找到，然后读取。
- 如果电台响应但读取不成功（例如有密码、型号不同），响应会列在详情中。如果电台卡在编程模式，请关闭再打开。

自动识别（4.0 - 4.7）
- 在“🔎 识别”标签页中点击“🔄 启用自动识别”。此后只要程序处于打开状态，当你连接编程线（或通过 USB 连接 DMR 电台）时，程序会自动搜索电台，使用与“识别电台”相同的只读命令：不会向电台写入任何内容。
- 它在程序的任何标签页中都有效。只有当连接到数据线的电台确实响应时，底部才会出现“正在识别电台，请稍候。”框（带“中断”），电台被识别或搜索结束后消失。从 4.4 起，线路噪声（0x00、0xFF 等，常见于没有连接电台或电台关机的数据线）以及发送命令的回声（即使延迟到达）都不算：至少需要 4 个真实字节或两个不同的响应。有多条数据线时，该框只显示有电台响应的端口。
- 电台被识别后，会显示其数据（也会在窗口中显示），并打开其标签页显示读取的信道；如果标签页中有未保存的更改，程序会先询问再替换。
- 从 4.2 起，识别后搜索会停止（功能仍保持启用）：要在同一条数据线上搜索另一台电台，请点击右上角“? 帮助”旁边的黄色按钮“🔎 识别电台”（自 4.4 起；自动识别关闭时它是灰色的，无法点击；打开很多标签页时会缩小到只剩放大镜）。之后连接到电脑的数据线（包括拔下后重新插上的同一条）会被自动搜索。
- 从 4.3 起，程序会持续监听所有已连接数据线的端口，每个端口独立且同时进行：电台关机或音量调到最小都不会停止搜索，只要数据线保持连接，搜索就会立即重新开始（不显示框）。因此你可以先连接数据线，之后再打开电台：电台一响应就会被识别。响应但不在支持范围内的电台会每 30 秒重试一次。
- 连接在不同数据线上的多台电台（例如 COM6 和 COM7）会同时搜索：每台都会显示数据并打开标签页；如果标签页已经打开，会显示提示“电台已识别！！电台标签页已打开”（多台电台时为“电台已识别！！电台标签页均已打开”）。识别后只有该电台的端口停止：其他端口继续监听。
- 识别过的电台会被记住（重启后也会）：之后的搜索会先尝试它们，搜索过程中每 8 次尝试会再试一次，因此用过的电台（例如 K67 Pro、Bajeton 8300、BJ-9000）几秒钟内就能识别。
- 只搜索编程线的端口（CH340、Prolific、Silicon Labs、FTDI 等 USB 转串口适配器），从不搜索蓝牙端口、调制解调器或系统串口（COM1、COM2）。
- 当你请求其他操作（读取、写入、固件、转发或手动识别）时，正在进行的自动搜索会自动中断。
- 该选择在关闭并重启程序后仍然保存。若不再使用，请回到“🔎 识别”标签页并点击“⏹ 停用自动识别”。
- （4.7）在尝试各型号之前，程序会先监听端口 1 秒（每个端口和速率每分钟一次）。处于固件升级模式的电台会自行发送周期性消息：这些字节不算作响应，因此搜索很快结束，“识别”标签页会提示电台可能处于升级模式（请正常关机再开机，或使用“固件”标签页）。
- （4.7）尝试顺序：已识别过的电台，已打开标签页的电台，然后是最常见的电台（K67 Pro、BJ-8300、BJ-7800 / RT-920、BJ-7700 / RT-900、BJ-9000 / RT-950 Pro、TD-H8、UV-17 / UV-17Pro、UV-K5、UV-5R、BF-888S），然后是其他电台。

DM-1701 的 USB 驱动（3.8）
- DM-1701（以及 Retevis RT84）以 DFU 模式通过 USB 连接（设备 0483:DF11），需要驱动。两种方式：
  1. 厂家的驱动（STTub30），位于“DM-1701 CPS”软件包的“DM-1701 USB Driver”文件夹：在 DM-1701 的“从电台读取”窗口中，“安装 USB 驱动…”按钮会要求选择安装程序（dpinst_amd64.exe 或 .inf 文件），并在 Windows 授权后启动它（对于 .inf 文件使用“pnputil /add-driver … /install”，适用于 Windows 10 和 11）；
  2. Windows 的通用 WinUSB 驱动，用 Zadig 安装（https://zadig.akeo.ie，Options → List All Devices，设备 0483 DF11，驱动 WinUSB）：与 dmrconfig 和 qdmr 使用的相同。这样操作后，厂家程序将无法再识别电台，直到重新安装其驱动。
- 程序会自动使用已安装的驱动；窗口会显示电台是否已连接以及使用哪个驱动。
- Windows 驱动不能包含在程序中，也不能重新分发：因此使用官方驱动（或 Windows 自带的 WinUSB）。

BTECH DMR-6X2：引导式固件升级（3.8）
- DMR-6X2（固件 2.21）和 DMR-6X2 PRO（固件 1.21）是 BTECH 品牌（BaofengTech，美国）的 DMR 电台。固件使用 BTECH 软件包中的官方程序“Firmware_Update”安装（CPS 的菜单 Tool → Firmware Upgrade，或 C:\DMR_6X2_2.21\Update\Firmware_Update.exe），电台需处于升级模式：关机，按住 PTT 和 Alarm（橙色键）并开机（LED 红色闪烁）；使用“USB Virtual Com Port Driver”的 COM 端口，921600 波特，Duplex，“Write”。升级固件（以及图标，开机时按 PTT + PF2）后，必须复位（开机时按 PTT + PF1），并重新写入事先保存的 codeplug：升级会清除编程数据。来源：官方软件包 DMR-6X2-221b 和 DMR-6X2-PRO-121e 中的“STOP and README FIRST.pdf”（https://baofengtech.com/software/）。
- 在型号库中，电台卡片 →“🧭 引导式升级…”：选择 .spi 文件，程序会检查 .spi、.CDI 和 .CDD 文件是否一致完整、适用于哪款电台（DMR-6X2 或 PRO：固件不能互换）、属于哪种升级（固件、图标、APRS 板）以及版本；显示正确的步骤并启动官方程序（也可以管理员身份运行）。
- 固件由 BTECH 程序写入：其协议未公开，程序是编译过的，因此无法与其他实现进行比对；出错可能使电台无法使用。

为不兼容电台查找方案（3.7）
在论坛和爱好者网站（CHIRP、RadioReference、miklor.com、RigPix、GitHub）中查找不兼容电台的程序或变通方法：
- UV-8D / BF-UV8：CHIRP 不支持（报告 #1225 仍未关闭，以及 #4519）：电台不指明哪些信道为空，2014 年的测试驱动写入的信道电台不显示；只能用厂家为 UV-8 提供的程序（中文）编程。此处不支持：没有该程序，结果无法验证。
- DM-5R（Tier I）：dmrconfig 支持 TD-5R，但明确注明“不支持 DM-5R”；该电台使用与其他 Baofeng 不同的数据线和原生程序。不支持（另一款电台 RD-5R 已支持）。若要支持需要（3.8）：其厂家程序（用 C++Builder 编写，即机器码：需用 Ghidra 或 IDR 等反汇编器研究，比 .NET 程序慢得多），尤其需要用串口监视器录制该程序与真实 DM-5R 之间的通信（读取和写入），以及程序保存的文件和该电台的专用数据线。
- DM-1702 / DM-1703：有可以读写存储的自由工具（MD1702-tools），但其作者自己警告，使用 L05 固件和 MD1706-V2 引导程序时曾使电台无法使用：出于谨慎不予支持。
- DM-V1：厂家自己的程序，micro-USB 数据线，转换器在电台内部；没有自由程序支持它。
- 没有公开程序的 PMR446（BF-T3、BF-T6…T57、BF-V1…V6A、BF-33C、BF-358……）：对于一些类似的电台，CHIRP 用户曾用 BF-888 的驱动取得部分成功（例如 BF-M4，报告 #7215，后来加入了 CHIRP）。这不是安全的方法：没有厂家程序，无法知道存储是否相同，写入不同的存储可能会使电台锁死。
- 5RHam、BJ-98 Plus、M20D：没有找到程序或技术资料。

导出
从档案（带筛选和勾选）或从电台的信道（全部或选中的）导出：
- Excel .xlsx 和 Excel 97-2003 .xls（首行冻结，有警告的行为黄色）；
- 意大利版 Excel 用 CSV（分隔符“;”，小数点为逗号）；
- CHIRP 用 CSV：CHIRP 的标准列。功率以瓦特写入（高 5.0W、中 2.0W、低 1.0W），这是较新版本 CHIRP 所要求的；亚音使用 Tone（仅发射）、TSQL（收发相同）、DTCS（相同 DCS 码）或 Cross（不同，包括 DCS→DCS、Tone→DTCS……）；从 3.7 起也支持仅接收信道（Duplex“off”）、DMR 信道（Mode“DMR”）以及所有电台的扫描设置。CHIRP 随后会把功率调整为目标电台的档位。

与旧版转换器的区别
- K67 现在会保留每个信道中未解析的字节，而不是将其清零。
- CHIRP CSV：功率以瓦特表示，取代 High/Mid/Low（较新版本的 CHIRP 会拒绝这些值）；收发亚音不同时写为 Cross（以前写为 TSQL，而 CHIRP 中 TSQL 只使用一个亚音）。

限制

- 设置：CHIRP 电台各项的说明是根据该项的英文名称编写的（许多驱动对同一功能使用不同的名称）：原始名称总是写在说明的末尾。
- 至少有一部分 K67 Pro 自称“BF-K6”（已用真实电台验证，3.7）：与原程序一样，如果最后读取的电台是同一型号，写入才会开始（启用备份时会自动先读取）。
- 识别：一些不同的电台使用相同的协议和存储，却不标明自己的型号：这时程序会列出可能的型号，由你选择。响应了其他系列协议的电台可能会停留在编程模式：请关机再开机。
- 从互联网下载使用直接连接（不使用系统代理）。
- 使用 CHIRP 驱动的电台：适用 CHIRP 对该型号的限制（例如 BJ-7800 是针对 V0.15P 固件编写的；如果电台的固件更新且响应不符合预期，读取会停止，不修改电台）。
- 固件：厂家没有说明让卡死的电台进入升级模式的步骤。自动识别会识别使用 Bajeton 8300（BT-11）编程协议的电台：使用相同协议的其他电台无法区分，因此还需要你的确认。

从源代码重新编译（可选）
需要 Go 1.22 或更高版本。在“sorgenti”文件夹中：
      go build -mod=vendor -trimpath -ldflags "-H=windowsgui -s -w -X main.buildDate=YYYY-MM-DDTHH:MM" -o "IU0VYT Flash.exe" .
（buildDate 是 Info 标签页中显示的编译日期，例如 2026-10-20T21:45。）
.exe 文件的图标和属性（名称、版本）位于 res/risorse.rc，编译为 rsrc_windows_amd64.syso（命令写在 .rc 文件开头）。
（库已包含在 vendor 文件夹中；图标在 rsrc_windows_amd64.syso 中。）
在 Linux 上，“go test -mod=vendor .”会对 testdata 中的示例文件并使用模拟电台运行自动测试。“verifica”文件夹包含与原始代码比较的程序（见 verifica/LEGGIMI_VERIFICA.txt）。
导入 IK2ANE 中继台列表的测试需要 testdata/pontixls.xls 文件（未包含：第三方数据，可从 www.ik2ane.it 下载）。
