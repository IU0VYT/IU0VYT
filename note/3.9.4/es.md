Página de la versión en GitHub (en inglés), con la descarga: [V.3.9.4](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.4)

IU0VYT Flash V.3.9.4 para Microsoft Windows 10/11

- Más robusto con archivos dañados: un archivo Excel (.xls) con una longitud de texto imposible se rechaza con un mensaje, en lugar de poder hacer que el programa se cierre por falta de memoria.
- Controles más estrictos de los números de los mapas de memoria de las radios.
- Ningún cambio para los archivos y las radios que ya funcionaban.
- Repositorio: instrucciones para informar en privado de problemas de seguridad (SECURITY.md) y actualizaciones de seguridad automáticas con Dependabot.
