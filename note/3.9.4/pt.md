Página da versão no GitHub (em inglês), com a transferência: [V.3.9.4](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.4)

IU0VYT Flash V.3.9.4 para Microsoft Windows 10/11

- Mais robustez com ficheiros danificados: um ficheiro Excel (.xls) com um comprimento de texto impossível é recusado com uma mensagem, em vez de poder fazer o programa fechar por falta de memória.
- Verificações mais rigorosas dos números dos mapas de memória dos rádios.
- Nenhuma alteração para os ficheiros e rádios que já funcionavam.
- Repositório: instruções para comunicar em privado problemas de segurança (SECURITY.md) e atualizações de segurança automáticas com o Dependabot.
