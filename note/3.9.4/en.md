IU0VYT Flash V.3.9.4 for Microsoft Windows 10/11

- More robust with damaged files: an Excel file (.xls) with an impossible text length is rejected with a message, instead of possibly making the program close for lack of memory.
- Stricter checks on the numbers of the radio memory maps.
- No change for the files and radios that already worked.
- Repository: instructions for reporting security problems privately (SECURITY.md) and automatic security updates with Dependabot.
