IU0VYT Flash V.3.9.4 для Microsoft Windows 10/11

- Больше надёжности при повреждённых файлах: файл Excel (.xls) с невозможной длиной текста отклоняется с сообщением, вместо того чтобы программа могла закрыться из-за нехватки памяти.
- Более строгие проверки чисел в картах памяти радиостанций.
- Никаких изменений для файлов и радиостанций, которые уже работали.
- Репозиторий: инструкции, как сообщать о проблемах безопасности конфиденциально (SECURITY.md), и автоматические обновления безопасности с Dependabot.
