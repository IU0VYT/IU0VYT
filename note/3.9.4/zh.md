GitHub 上的发布页面（英文），含下载：[V.3.9.4](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.4)

IU0VYT Flash V.3.9.4，适用于 Microsoft Windows 10/11

- 对损坏文件更稳健：文本长度不可能的 Excel 文件（.xls）会被拒绝并给出提示，而不会因内存不足导致程序关闭。
- 对电台存储器映射中的数字进行更严格的检查。
- 已能正常使用的文件和电台不受任何影响。
- 代码仓库：私下报告安全问题的说明（SECURITY.md），以及通过 Dependabot 自动进行的安全更新。
