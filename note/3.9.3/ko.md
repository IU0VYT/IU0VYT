GitHub 릴리스 페이지(영어), 내려받기 포함: [V.3.9.3](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.3)

Microsoft Windows 10/11용 IU0VYT Flash V.3.9.3

- 무전기 탭: 모든 채널에 체크 상자가 생겼고 «☑ 모두 선택», «☐ 모두 선택 해제»가 있습니다.
- «복사 대상…» 대신 «📻 다른 무전기로 전달»: 체크한 채널을 제조사와 모델로 고른 연결된 다른 무전기에 바로 씁니다. 확인, 호환성 검사, 조정, 무전기 백업, 최종 확인을 거칩니다.
- 중계기 보관함: 체크한 중계기의 «🗑 삭제»와 새 «🗑 모두 삭제».
- 홈 화면과 정보 탭에 프로그램 웹사이트와 소스 코드 링크.
