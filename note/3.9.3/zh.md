GitHub 上的发布页面（英文），含下载：[V.3.9.3](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.3)

IU0VYT Flash V.3.9.3，适用于 Microsoft Windows 10/11

- 电台标签页：每个信道都有复选框，并提供“☑ 全选”和“☐ 全不选”。
- “📻 转发到其他电台”取代“复制到…”：勾选的信道直接写入另一台已连接的电台（按品牌和型号选择），包括确认、兼容性检查、自动调整、电台备份和最终校验。
- 中继台档案：对勾选的中继台使用“🗑 删除”，并新增“🗑 全部删除”。
- 首页和“信息”标签页中加入程序网站和源代码的链接。
