GitHub 上的发布页面（英文），含下载：[V.3.9.2](https://github.com/IU0VYT/IU0VYT/releases/tag/V.3.9.2)

IU0VYT Flash V.3.9.2，适用于 Microsoft Windows 10/11

- 写入后校验：如果电台在写入结束时重启（例如 Bajeton BJ-8300），回读会等待并重试，直到电台再次就绪；适用于所有电台。
- Bajeton BJ-8300 使用 BT-11_CPS v1.0.9 的文件：信道分为 15 个区域、每区 64 个，或合为一个 960 个信道的列表，与原厂程序相同（标签页中的“信道”选项）。
- 首页和网站上的“IU0VYT”标题改为霓虹绿。
- 稳定性修正和安装包整理。
