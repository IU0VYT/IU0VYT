IU0VYT Flash V.4.45.0（Microsoft Windows 10/11 用）

### 新機能
- **AnyTone ファミリーの DMR 無線機**：AnyTone AT-D868UV、AT-D878UV / AT-D878UV Plus、AT-D878UV II Plus、BTECH DMR-6X2 と DMR-6X2 PRO（この 2 機種はこれまで「非対応」でした）。無線機の USB ケーブルでチャンネルとゾーンを扱います。メモリーとプロトコルはフリーのプログラム dmrconfig から取り、その元のコードで確認しました。書き込むのはチャンネル、ゾーン、スキャンリストだけです。
- 純正ファームウェアの **TYT MD-UV380、MD-UV390、MD-2017、MD-9600 と Retevis RT3S、RT82**：Baofeng DM-1701 と同じメモリーとプロトコル。
- **Baofeng BF-666S**（BF-888S のドライバー）と **BF-T6**（実験的、BF-T8 のドライバー）。
- 「非対応」のままのカード UV-8D、BF-UV8、DM-1702、DM-1703 には、その理由を書き添えました。
- ギャラリー：54 メーカー 673 機種（チャンネル対応 623、設定対応 556）。

### 注意
- 新しい無線機はどれも実機で試験していません：まずは読み込みだけ行ってください。
- BTECH DMR-6X2 PRO と Baofeng BF-T6 は実験的です。
- 本プログラムは独立したもので、無線機メーカーとは関係ありません。
- 全テストに合格：一般部分、918 件の構造比較と CHIRP と同一の 381 件の読み込み / 書き込み、AnyTone ファミリーは dmrconfig の元のコードと比較。

このバージョンには、単独の安定版リリースがなかった 4.24.0 から 4.44.0 までの各バージョンの新機能も含まれます。新しい順に記載します。

## IU0VYT Flash 4.44.0

### 新機能
- チャンネルにしか対応していなかった 8 機種に**設定**を追加：Radtel RT-480、RT-68、RT-5D、RT-69 GPS、RT-4D、RT-6D、RT-1000 Pro、Bajeton DM-5000。メーカーのプログラムから。
- **RT-480 と RT-68**：書き込み時に全般設定のブロックも無線機に送るようになりました。
- **RT-4D、RT-6D、RT-1000 Pro**：無線機のファイルに設定も入るようになりました（以前に保存したファイルもそのまま使えます）。

### 注意
- 新しい設定はどれも実機で試験していません。
- RT-69 GPS：今のところ、メーカーのプログラムで 1 つずつ確認した項目だけです。

### 注意

### 新機能
- **見やすくなった「機種」タブ**：無線機の種類のラベルをページの中央に置き、対応と非対応の無線機を分ける線を赤く太くしました。
- **無線機を 26 機種追加**。すでにある同じ無線機のドライバーで扱います：
  - メーカーのプログラムの比較で判明：**Bajeton BT-8000**、**Radioddity GC-5**、**Trivox**、**PR-T5**、**GT-82**、**Retevis RT28**；
  - CHIRP の同等機種の表から：Radioddity GA-5S、Retevis RT5（出力 3 段階）、RT5R、RT5RV、RT5、TIDRADIO TD-UV5R TriPower、TechSide TI-F8+ と TS-T9+、Rugged RH5R と RH5X、Ansoko A-5R と A-8S、Arcshell AR-5、AR-6、AR-8、Greaval GV-8S と GV-9S、Tenway TW-325、UV-82 Pro、UV-5R Pro。

### 注意
- メーカーのプログラムの比較で判明した 6 機種は、まだ実機で試験していません：まずは読み込みだけ行ってください。機種が違う場合、無線機は応答せず、変更もされません。
