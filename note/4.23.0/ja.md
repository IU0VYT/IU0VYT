IU0VYT Flash V.4.23.0（Microsoft Windows 10/11 用）

### 新機能
- **Kenwood TK-481 と TK-981**（900 MHz、チャンネルはシステムに分かれる）と、車載機 **TK-780 と TK-880**：チャンネルと設定、CHIRP のドライバーで。
- **Kenwood TK-2180 / TK-3180 / TK-7180 / TK-8180**：無線機の設定にも対応。
- **Radtel RT-13**：チャンネル（22、名前なし）、メーカーのプログラムから導出。
- **Radtel RT-69 GPS**：チャンネル（999、名前は 12 文字）、メーカーのプログラムから導出。書き込み前に、各チャンネルが無線機のバンド内にあるかを確認します。
- 壊れたファイルに強く：Baofeng UV-B5 / UV-B6 と UV-3R のトーンを読むときの 2 つの異常終了を修正。
- 変換：変換先の無線機に保存できないチャンネルは、変換を止めずに警告付きでスキップします（IJV、nicFW、OpenGD77、UV-KX、R3b0rn のファームウェア、Radtel RT-480 / RT-68、RT-830 / RT-850）。
- ギャラリー：47 メーカー 569 機種（チャンネル対応 515、設定対応 433）。

### 注意
- TK-481 / TK-981：無線機にすでにあるシステムだけを使います。共有リソース（トランキング）のシステムは変更しません。
- RT-13 と RT-69 GPS：無線機にパスワードが設定されている場合は、先に Radtel のプログラムで解除してください。メーカーのプログラムから導出し、模擬無線機でのみ試験しています：まずは読み込みだけ行ってください。
- 本プログラムは独立したもので、無線機メーカーとは関係ありません。

---

このバージョンには、テスト版としてのみ公開された 4.13.0 から 4.22.0 までの各バージョンの新機能も含まれます。新しい順に記載します。

## IU0VYT Flash 4.22.0

### 新機能
- **Radtel RT-480 と RT-68**：チャンネルと名前（256 チャンネル、0 から 255 の番号、名前は 12 文字）、メーカーのプログラムから導出。周波数、名前、出力、帯域幅、スキャン、トーンを変更できます。チャンネルのほかの項目はそのままです。
- **Radtel RT-830 と RT-850**：チャンネル（128、名前なし）、メーカーのプログラムから導出。周波数、出力、帯域幅、スキャン、トーンを変更できます。
- **Radtel RT-20M**：Ruyage UV58Plus のタブで開きます（iRadio UV-5118plus と同じメモリー）。

### 注意
- RT-480 / RT-68：書き込むのはチャンネルと名前だけで、無線機の設定、VFO、DTMF には触れません。周波数は 1.25 kHz ステップ。各チャンネルには送信周波数が必要です。
- RT-830 / RT-850：設定と VFO は元のまま戻します。無線機のパスワードは決して書き込みません。パスワードが設定されている場合は、先に Radtel のプログラムで解除してください。
- いずれもメーカーのプログラムから導出し、模擬無線機でのみ試験しています：まずは読み込みだけ行ってください。

## IU0VYT Flash 4.21.0

### 新機能
- **Radtel RT-5D（DMR）**：チャンネル（64 ずつ 16 ゾーン、名前は 12 文字）、メーカーのプログラムから導出。周波数、名前、出力、帯域幅、スキャン、トーンを変更できます。チャンネルのほかの項目はそのままです。
- **Kenwood TK-2180、TK-3180K、TK-3180K2、TK-3180E** と車載機 **TK-7180、TK-8180**（E も）：チャンネル、CHIRP のドライバーで。リストには最初の 32 ゾーンそれぞれに 250 の位置があります。使うのは無線機にすでにあるゾーンだけで、合計 512 チャンネルです。

### 注意
- RT-5D：読み込みはメモリー全体を取得し、書き込みは Radtel のプログラムと同じく、ファイルの内容をそのまま全部送り返します。書き込む前に新しく読み込んでください。古いファイルだと当時の連絡先と設定が戻ってしまいます。模擬無線機でのみ試験しています。
- TK-x180：チャンネルのみで設定はなし。ゾーンの作成や削除はしません。無線機に通常以外の（トランキングの）ゾーンがある場合、読み込みを拒否します。

## IU0VYT Flash 4.20.0

### 新機能
- **Radtel RT-4D と RT-6D（DMR）および RT-1000 Pro**：チャンネル（1024、名前は 16 文字）とゾーン（250）、メーカーのプログラムから導出。周波数、名前、出力、帯域幅、トーン、そして RT-4D と RT-6D ではスキャンを変更できます。チャンネルのほかの項目はそのままです。書き込むのはチャンネルとゾーンだけで、連絡先、グループ、メッセージ、FM ラジオ、設定には触れません。

### 注意
- 模擬無線機でのみ試験しています：まずは読み込みだけ行い、問題があれば知らせてください。
- 「識別」では、同じ接続方式のほかの Radtel や Bajeton の無線機とこれらを区別できません：タブは手で選んでください。
- RT-1000 Pro：スキャン除外は扱いません（無線機の状態のままです）。

## IU0VYT Flash 4.19.0

### 新機能
- **Radtel RT-817A / RT-871A**：チャンネル（1024、名前は 16 文字）、メーカーのプログラムから導出。RT-880G と同じ接続方式とチャンネル形式で、ゾーンはありません。読み書きするのは Radtel のプログラムが使う領域（設定、チャンネル、FM ラジオ）だけで、ロゴには触れません。

### 注意
- 模擬無線機でのみ試験しています：まずは読み込みだけ行い、問題があれば知らせてください。
- 「識別」では RT-817A / RT-871A と RT-880G を区別できません：タブは手で選んでください。

## IU0VYT Flash 4.18.0

### 新機能
- **Kenwood TK-2140、TK-3140、TK-280、TK-380**：チャンネルがゾーン（グループ）に分かれた業務用ハンディ機。チャンネルと設定に対応。リストにはメモリーの 250 の位置が表示され、新しいチャンネルは直前のチャンネルと同じゾーンに入ります。
- **fagci の R3b0rn ファームウェアを入れた Quansheng UV-K5 / UV-K6**：チャンネル（元のメモリーで 298、より大きなメモリーで最大 1024）。設定、VFO、プリセット、SSB 補正は決して書き込みません。
- **Radtel RT-330 と RT-400**：チャンネル、メーカーのプログラムから導出。

### 注意
- TK ハンディ機の CHIRP ドライバーは実験的と明記されています。プログラムからゾーンの作成や削除はしません。
- R3b0rn ファームウェア、RT-330、RT-400 は模擬無線機でのみ試験しています：まずは読み込みだけ行い、問題があれば知らせてください。
- R3b0rn ファームウェアでは、名前のないチャンネルは周波数が名前になります（このファームウェアには名前のないチャンネルは存在しません）。
- RT-400 のタブは、RT-470、RT-630、RT-495、HI-8811 と名乗る無線機を拒否します：RT-400 でのみ使ってください。

## IU0VYT Flash 4.17.0

  - 60G シリーズ：TK-260G、TK-270G、TK-272G、TK-278G、TK-360G、TK-370G、TK-372G、TK-378G、TK-388G。
- **Radtel RT-860**：「Radtel RT-880G」のタブを使います（同じ接続方式、同じチャンネルのメモリー）。

### 注意
- Kenwood TH-F6/F7、TH-G71、TH-D7、TH-K2 は CHIRP のドライバーのコマンドを使い、模擬無線機でのみ試験しています：まずは読み込みだけ行い、問題があれば知らせてください。
- TK ハンディ機の CHIRP ドライバーは実験的と明記されています。
- RT-860 はメーカーのプログラムとの比較から作ったもので、実機では試験していません。

## IU0VYT Flash 4.16.0

### 新機能
- **OpenGD77**：フリーの OpenGD77 ファームウェアを入れた DMR 無線機のチャンネル。
  - Radioddity GD-77 と GD-77S、Baofeng DM-1801 と RD-5R。
  - Baofeng DM-1701、TYT MD-UV380、MD-380、MD-9600、MD-2017、Retevis RT3S と RT84。
  - 無線機は USB シリアルポートとして見えます。書き込むのは変更したチャンネルとゾーンだけで、設定、連絡先、グループ、キャリブレーションは決して書き込みません。
- **Quansheng UV-K5、ほかのフリーのファームウェア**：
  - kamilsss655 の **NUNU**：チャンネルと設定。
  - joaquim.org の **UV-KX**：チャンネルと設定。キャリブレーションは決して書き込みません。
  - 「OSFW」タブは、バンドを広げた改造版の純正ファームウェア（uvmod-kitchen、Tunas1337 のコレクション）にも使えます。

### 注意

- NUNU と UV-KX は、それぞれの作者による CHIRP 用ドライバーと 1 バイト単位で比較しています。

## IU0VYT Flash 4.15.0

### 新機能
- **D-STAR と C4FM**：アマチュア無線のデジタルハンディ機のチャンネルをケーブルで扱い、.img ファイルは CHIRP と互換です。「方法」の列に「D-STAR」または「C4FM」と表示します。
  - **Icom** ID-31A/E、ID-51A/E、ID-51 Plus、ID-51 Plus2（D-STAR）と IC-E90 / IC-T90。
  - **Yaesu** VX-6、VX-3、FT-70D、FT1D、FT2D、FT3D、FT5D（コピーは無線機側から開始します：手順はケーブルのウィンドウにあります）。
  - **Kenwood**（新しいメーカー、合計 47）TH-D72、TH-D74、TH-D75、USB ケーブルで。
  - IC-E90、VX-6、VX-3、FT-70D、FT1D、FT2D、FT3D、FT5D、TH-D72 の設定。
- **フリーのファームウェア**：
  - TIDRADIO TD-H3 の **nicFW 2.x**：チャンネルと主な設定。
  - Radtel RT-880、RT-880G、RT-950 Pro の **nicFW880 / nicFW950**：チャンネル。
  - Quansheng UV-K1 と UV-K5 V3 の **F4HWN Fusion 5.x**：1024 チャンネルと設定。
  - nicFW では無線機のキャリブレーションを決して書き込みません。
- **ギャラリーの Kenwood**：PMR446 と DMR/NXDN のハンディ機も、非対応機種として掲載（販売店向けの KPG プログラムでしか設定できません）。

### 修正
- 設定：一度も使われていないテキスト欄は「想定外の値」ではなく空として読みます。変更していない値は書き直しません。
- Puxing PX-888K：誤った値を書き込むおそれのある設定項目を 6 つ削除（BOT/EOT コードと DTMF の時間）。
- Yaesu VX-3：DTMF コードにスペースを使えなくしました（無線機にスペースがないため）。

### 注意
- ドライバーは CHIRP のドライバー（GNU GPL）、nicsure が公開した資料（nicFW）、F4HWN のドライバーをもとにゼロから書き、模擬無線機で 1 バイト単位で比較しています。このバージョンの実機はまだ試験していません：バックアップを保存し、問題があれば知らせてください。
- Icom、Yaesu、Kenwood にはファームウェア更新はありません（メーカーのプログラムで行います）。

## IU0VYT Flash 4.14.0

### 新機能

  - **Yaesu** FT-4XR、FT-4XE、FT-4VR、FT-65R、FT-65E、FT-25R（SCU-35 ケーブル）と FT-60R/E（無線機側から開始するコピー、「F8 CLONE」）。

- Wouxun KG-UV8D：内部のフィールド名を現在の CHIRP に合わせました（チャンネルへの影響なし）。

### 注意

- マレー語とヒンディー語の翻訳は新しいものです：分かりにくい文があれば知らせてください。

## IU0VYT Flash 4.13.1

### 新機能
- Quansheng UV-K5、UV-K5 V3、UV-K1 用の **IJV ファームウェア**（IU0IJV による非純正ファームウェア、[ijvradio.com](https://www.ijvradio.com/)）：ファームウェアのバージョンごとに 1 つ、合計 5 つのタブ。
  - 従来の UV-K5（ハードウェア V1）の **V3**、200 または 999 チャンネル。
  - UV-K5 V3 と UV-K1 の **V4**、**V5（「FW5」）**、**V6**：無線機で選んだバンクの 500 チャンネル、グループ名とバンク名付き。
  - チャンネルと主な設定（メニュー、表示、VOX、サイドキー）を読み書きします。書き込み前に、無線機で同じバンクが選ばれたままかを確認し、変更した部分だけを書き込みます。キャリブレーションには決して触れません。
  - **V6（4.13.1 の新機能）**：V6 のデータリンク、4 KiB のセクター単位で書き込み、各セクターを読み直して確認。データリンクがないと無線機が示した場合は、RadioManager の FLASH V6 で更新してください。
- **ファームウェア更新**：IJV のバージョンを含む .bin ファイルを見分け、チャンネルに使うタブを示し、V5 と V6 には警告を出します。
- 11 言語すべてに翻訳。

### 注意
- プロトコルとメモリーは、IJV が公開した CHIRP モジュールと RadioManager 4.3.2 の解析から導き、コードはゼロから書き、模擬無線機で試験しました。IJV を入れた実機はまだ試験していません：問題があれば知らせてください。
- IJV のモジュール、項目、ライセンス、ファームウェアは IJV の RadioManager のものです。
