GitHub 릴리스 페이지(영어), 내려받기 포함: [V.4.10.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.10.0)

Microsoft Windows 10/11용 IU0VYT Flash V.4.10.0

### 9개 언어 지원
- «ℹ 정보» 바로 오른쪽에 국기가 있는 새 언어 선택기: italiano, English, Français, Deutsch, Español, Português, Русский, 中文, 日本語.
- 다시 시작하지 않아도 바로 번역됩니다: 탭, 버튼, 메뉴, 창, 안내서, 메시지와 경고(무전기에서 오는 것 포함), 갤러리 카드, 설정, Windows의 «열기»와 «저장» 창.
- 마지막으로 고른 언어는 다시 시작해도 기억됩니다.
- 정보 파일은 `lingue` 폴더(언어별 하위 폴더)에 번역되어 있습니다: 전체 안내서, README, 4.10 새 기능이 담긴 CHANGELOG, 저자와 라이선스, 버전, 라이선스 안내. 유효한 라이선스는 여전히 GNU GPL 영어 원문(LICENSE.txt)입니다.

### 위쪽 막대
- «업데이트» 버튼을 없앴습니다: 확인은 시작할 때마다 자동으로 이루어지며 정보 탭의 «🔄 업데이트 확인»으로도 할 수 있습니다.
- «🔎 무전기 식별»이 이제 «? 안내» 옆에 있습니다.

### 펌웨어 업데이트: 무전기 5종 추가(모두 57종)
- Radtel RT-890: Radtel .bin 파일과 자유 펌웨어(M7OCM, OEFW). M7OCM 펌웨어를 올린 뒤에는 그 전용 탭으로 채널을 관리합니다.
- USB로 연결하는 Baofeng DM-1701 / Retevis RT84, Baofeng .bin 파일 사용: 프로그램 메모리만 쓰며 무전기의 부트로더는 건드리지 않습니다.
- USB로 연결하는 Baofeng RD-5R과 DM-1801(드라이버 불필요), 제조사 .sgl 파일 사용: 무전기가 메모리를 지우기 전에 모델을 확인합니다.

### 설정: 무전기 10종 추가(모두 396종)
- Feidaxin FD-288A, FD-150A, FD-160A, FD-450A, FD-460A, FD-460UH와 Retevis RT76P(CHIRP 기반).
- Baofeng RD-5R과 DM-1801(31개 항목), Baofeng DM-1701(이름, DMR ID, 켤 때 문구).

프로토콜은 처음부터 다시 작성했고 가상 무전기와 제조사의 실제 파일로 시험했지만 실제 무전기로는 시험하지 않았습니다. 백업은 항상 보관하세요.

갤러리: 44개 제조사 489개 모델(채널 451, 설정 396, 펌웨어 업데이트 57).
