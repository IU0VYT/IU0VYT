Página de la versión en GitHub (en inglés), con la descarga: [V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

IU0VYT Flash V.4.12.0 para Microsoft Windows 10/11

### Idioma en el primer inicio
- La primera vez que se abre, el programa arranca en el idioma de Windows del usuario (Configuración → Hora e idioma → Idioma). Si el idioma de Windows no está entre los 11 del programa, arranca en inglés.
- Si luego eliges otro idioma con las banderas, la elección se guarda y vale en cada reinicio (también el italiano).
- Quien había elegido el italiano con la 4.10 o la 4.11 solo lo recupera si Windows está en italiano; si no, basta con elegirlo una vez con la bandera.

### Traducciones
- «Sí» y «No» (columna Escaneo y otras) y el nombre de la licencia en la página inicial están ahora traducidos en todos los idiomas.

### Seguridad
- Correcciones a los avisos del análisis automático del código de GitHub (CodeQL): escritura de números en la memoria de la radio, carpeta de datos indicada por variable de entorno, texto de las instrucciones del firmware, herramientas de verificación.

### Repositorio y sitio web
- README en inglés en la página principal del repositorio (original italiano en `README.it.md`), con las banderas de los 11 idiomas, las insignias y las imágenes del programa.
- Política de seguridad (pestaña «Security») en inglés, con las traducciones a los otros 10 idiomas.
- Sitio web: textos actualizados, imagen de vista previa para las redes sociales y aviso automático a los buscadores (IndexNow) en cada publicación.
