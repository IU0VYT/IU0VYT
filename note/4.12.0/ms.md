Halaman keluaran di GitHub (dalam bahasa Inggeris), dengan muat turun: [V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

IU0VYT Flash V.4.12.0 untuk Microsoft Windows 10/11

### Bahasa semasa dimulakan kali pertama
- Pada kali pertama dibuka, program bermula dalam bahasa Windows pengguna (Tetapan → Masa & bahasa → Bahasa). Jika bahasa Windows bukan salah satu daripada 11 bahasa program, ia bermula dalam bahasa Inggeris.
- Jika kemudian anda memilih bahasa lain dengan bendera, pilihan itu disimpan dan berlaku setiap kali dimulakan semula (termasuk bahasa Itali).
- Sesiapa yang memilih bahasa Itali dengan 4.10 atau 4.11 hanya akan mendapatnya semula jika Windows dalam bahasa Itali; jika tidak, pilih sekali sahaja dengan bendera.

### Terjemahan
- «Ya» dan «Tidak» (lajur Imbasan dan lain-lain) serta nama lesen pada halaman permulaan kini diterjemahkan dalam semua bahasa.

### Keselamatan
- Pembetulan bagi amaran analisis kod automatik GitHub (CodeQL): penulisan nombor ke memori radio, folder data yang ditetapkan melalui pemboleh ubah persekitaran, teks arahan perisian tegar, alat semakan.

### Repositori dan laman web
- README dalam bahasa Inggeris pada halaman utama repositori (asal bahasa Itali dalam `README.it.md`), dengan bendera 11 bahasa, lencana dan gambar program.
- Dasar keselamatan (tab «Security») dalam bahasa Inggeris, dengan terjemahan dalam 10 bahasa lain.
- Laman web: teks dikemas kini, imej pratonton untuk media sosial dan notis automatik kepada enjin carian (IndexNow) pada setiap penerbitan.
