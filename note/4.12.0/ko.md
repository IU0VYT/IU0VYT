GitHub 릴리스 페이지(영어), 내려받기 포함: [V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

Microsoft Windows 10/11용 IU0VYT Flash V.4.12.0

### 처음 시작할 때의 언어
- 처음 열 때 프로그램은 사용자의 Windows 언어로 시작합니다(설정 → 시간 및 언어 → 언어). Windows 언어가 프로그램의 11개 언어에 없으면 영어로 시작합니다.
- 그 뒤 국기로 다른 언어를 고르면 그 선택이 저장되어 다시 시작할 때마다 적용됩니다(이탈리아어도 마찬가지).
- 4.10이나 4.11에서 이탈리아어를 골랐던 사용자는 Windows가 이탈리아어일 때만 그대로 쓰게 됩니다. 아니면 국기로 한 번만 다시 고르면 됩니다.

### 번역
- «예»와 «아니요»(스캔 열 등)와 시작 페이지의 라이선스 이름이 이제 모든 언어로 번역됩니다.

### 보안
- GitHub 자동 코드 분석(CodeQL) 경고 수정: 무전기 메모리에 숫자 쓰기, 환경 변수로 지정하는 데이터 폴더, 펌웨어 안내 문구, 확인 도구.

### 저장소와 웹사이트
- 저장소 첫 페이지의 README를 영어로(이탈리아어 원문은 `README.it.md`). 11개 언어 국기, 배지, 프로그램 이미지 포함.
- 보안 정책(«Security» 탭)을 영어로, 나머지 10개 언어 번역 포함.
- 웹사이트: 문구 업데이트, 소셜 네트워크용 미리보기 이미지, 게시할 때마다 검색 엔진에 자동 알림(IndexNow).
