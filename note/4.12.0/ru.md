Страница выпуска на GitHub (на английском), со ссылкой для загрузки: [V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

IU0VYT Flash V.4.12.0 для Microsoft Windows 10/11

### Язык при первом запуске
- При первом открытии программа запускается на языке Windows пользователя (Параметры → Время и язык → Язык). Если языка Windows нет среди 11 языков программы, она запускается на английском.
- Если затем выбрать другой язык флагами, выбор сохраняется и действует при каждом перезапуске (итальянский тоже).
- Кто выбирал итальянский в 4.10 или 4.11, получит его снова, только если Windows на итальянском; иначе достаточно один раз выбрать его флагом.

### Переводы
- «Да» и «Нет» (столбец «Сканирование» и другие) и название лицензии на начальной странице теперь переведены на все языки.

### Безопасность
- Исправления по предупреждениям автоматического анализа кода GitHub (CodeQL): запись чисел в память радиостанции, папка данных, заданная переменной окружения, текст инструкций по прошивке, инструменты проверки.

### Репозиторий и сайт
- README на английском на главной странице репозитория (итальянский оригинал в `README.it.md`), с флагами 11 языков, значками и изображениями программы.
- Политика безопасности (вкладка «Security») на английском, с переводами на остальные 10 языков.
- Сайт: обновлённые тексты, картинка предпросмотра для соцсетей и автоматическое уведомление поисковых систем (IndexNow) при каждой публикации.
