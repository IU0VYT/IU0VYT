IU0VYT Flash V.4.12.0 for Microsoft Windows 10/11

### Language at first start
- The first time it opens, the program starts in the user's Windows language (Settings → Time & language → Language). If the Windows language is not one of the program's 11, it starts in English.
- If you then choose another language with the flags, the choice is saved and applies at every restart (Italian too).
- Anyone who had chosen Italian with 4.10 or 4.11 gets it back only if Windows is in Italian; otherwise just choose it once with the flag.

### Translations
- «Yes» and «No» (Scan column and others) and the name of the licence on the start page are now translated in all languages.

### Security
- Fixes for the alerts of GitHub's automatic code analysis (CodeQL): writing numbers into the radio memory, data folder given by an environment variable, text of the firmware instructions, verification tools.

### Repository and website
- English README on the main page of the repository (Italian original in `README.it.md`), with the flags of the 11 languages, badges and pictures of the program.
- Security policy («Security» tab) in English, with translations into the other 10 languages.
- Website: updated texts, preview image for social networks and automatic notice to search engines (IndexNow) at every publication.
