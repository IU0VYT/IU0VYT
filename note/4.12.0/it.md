IU0VYT Flash V.4.12.0 per Microsoft Windows 10/11

*English: at the first start the program now uses the Windows language (English if it is not one of the 11 available); the language chosen with the flags is saved. «Yes»/«No» and the license name are translated, fixes for the GitHub code scanning (CodeQL) alerts, English README with language flags and screenshots, security policy in 11 languages.*

### Lingua al primo avvio
- Alla prima apertura il programma parte nella lingua di Windows dell'utente (Impostazioni → Ora e lingua → Lingua). Se la lingua di Windows non è fra le 11 del programma, parte in inglese.
- Se poi scegli un'altra lingua con le bandiere, la scelta si salva e vale a ogni riavvio (anche l'italiano).
- Chi aveva scelto l'italiano con la 4.10 o la 4.11 lo ritrova solo se Windows è in italiano; altrimenti basta sceglierlo una volta con la bandiera.

### Traduzioni
- «Sì» e «No» (colonna Scansione e altre) e il nome della licenza nella pagina iniziale ora sono tradotti in tutte le lingue.

### Sicurezza
- Correzioni alle segnalazioni dell'analisi automatica del codice di GitHub (CodeQL): scrittura dei numeri nella memoria della radio, cartella dei dati indicata da variabile d'ambiente, testo delle istruzioni del firmware, strumenti di verifica.

### Repository e sito
- README in inglese nella pagina principale del repository (originale italiano in `README.it.md`), con le bandiere delle 11 lingue, i distintivi e le immagini del programma.
- Politica di sicurezza (scheda «Security») in inglese, con le traduzioni nelle altre 10 lingue.
- Sito: testi aggiornati, immagine di anteprima per i social e avviso automatico ai motori di ricerca (IndexNow) a ogni pubblicazione.
