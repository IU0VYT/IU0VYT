Página da versão no GitHub (em inglês), com a transferência: [V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

IU0VYT Flash V.4.12.0 para Microsoft Windows 10/11

### Língua no primeiro arranque
- Na primeira abertura, o programa arranca na língua do Windows do utilizador (Definições → Hora e idioma → Idioma). Se a língua do Windows não for uma das 11 do programa, arranca em inglês.
- Se depois escolher outra língua com as bandeiras, a escolha é guardada e vale em cada reinício (também o italiano).
- Quem tinha escolhido o italiano com a 4.10 ou a 4.11 só o reencontra se o Windows estiver em italiano; caso contrário, basta escolhê-lo uma vez com a bandeira.

### Traduções
- «Sim» e «Não» (coluna Busca e outras) e o nome da licença na página inicial estão agora traduzidos em todas as línguas.

### Segurança
- Correções aos alertas da análise automática do código do GitHub (CodeQL): escrita de números na memória do rádio, pasta de dados indicada por variável de ambiente, texto das instruções do firmware, ferramentas de verificação.

### Repositório e site
- README em inglês na página principal do repositório (original italiano em `README.it.md`), com as bandeiras das 11 línguas, os distintivos e as imagens do programa.
- Política de segurança (separador «Security») em inglês, com as traduções nas outras 10 línguas.
- Site: textos atualizados, imagem de pré-visualização para as redes sociais e aviso automático aos motores de busca (IndexNow) em cada publicação.
