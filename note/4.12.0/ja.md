IU0VYT Flash V.4.12.0（Microsoft Windows 10/11 用）

### 初回起動時の言語
- 初めて開いたとき、プログラムはユーザーの Windows の言語で起動します（設定 → 時刻と言語 → 言語）。Windows の言語がプログラムの 11 言語にない場合は英語で起動します。
- その後、国旗で別の言語を選ぶと、その選択が保存され、毎回の起動で使われます（イタリア語も同様）。
- 4.10 または 4.11 でイタリア語を選んでいた場合、Windows がイタリア語のときだけそのまま使われます。そうでなければ国旗で一度選び直してください。

### 翻訳
- 「はい」「いいえ」（スキャン列など）と、スタートページのライセンス名が全言語で翻訳されました。

### セキュリティ
- GitHub の自動コード分析（CodeQL）の指摘を修正：無線機のメモリーへの数値の書き込み、環境変数で指定するデータフォルダー、ファームウェアの説明文、確認用ツール。

### リポジトリとウェブサイト
- リポジトリのメインページの README を英語に（イタリア語の原文は `README.it.md`）。11 言語の国旗、バッジ、プログラムの画像付き。
- セキュリティポリシー（「Security」タブ）を英語にし、ほかの 10 言語の翻訳も用意。
- ウェブサイト：文章を更新し、SNS 用のプレビュー画像と、公開のたびに検索エンジンへ自動で知らせる仕組み（IndexNow）を追加。
