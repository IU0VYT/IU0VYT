IU0VYT Flash V.4.12.0 لنظام Microsoft Windows 10/11

### اللغة عند التشغيل الأول
- عند الفتح لأول مرة يبدأ البرنامج بلغة Windows لدى المستخدم (الإعدادات ← الوقت واللغة ← اللغة). إذا لم تكن لغة Windows من لغات البرنامج الـ 11، يبدأ بالإنجليزية.
- إذا اخترت بعد ذلك لغة أخرى بالأعلام، يُحفظ الاختيار ويسري عند كل إعادة تشغيل (الإيطالية أيضًا).
- من اختار الإيطالية مع 4.10 أو 4.11 لا يجدها مجددًا إلا إذا كان Windows بالإيطالية؛ وإلا يكفي اختيارها مرة واحدة بالعلم.

### الترجمات
- «نعم» و«لا» (عمود المسح وغيره) واسم الترخيص في الصفحة الأولى مترجمة الآن في جميع اللغات.

### الأمان
- إصلاحات لتنبيهات التحليل التلقائي للشيفرة في GitHub ‏(CodeQL): كتابة الأرقام في ذاكرة الجهاز، ومجلد البيانات المحدد بمتغير بيئة، ونص تعليمات البرنامج الثابت، وأدوات التحقق.

### المستودع والموقع
- ملف README بالإنجليزية في الصفحة الرئيسية للمستودع (الأصل الإيطالي في `README.it.md`)، مع أعلام اللغات الـ 11 والشارات وصور البرنامج.
- سياسة الأمان (علامة تبويب «Security») بالإنجليزية، مع ترجمات إلى اللغات العشر الأخرى.
- الموقع: نصوص محدّثة، وصورة معاينة لشبكات التواصل، وإشعار تلقائي لمحركات البحث (IndexNow) عند كل نشر.
