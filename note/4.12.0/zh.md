GitHub 上的发布页面（英文），含下载：[V.4.12.0](https://github.com/IU0VYT/IU0VYT/releases/tag/V.4.12.0)

IU0VYT Flash V.4.12.0，适用于 Microsoft Windows 10/11

### 首次启动时的语言
- 第一次打开时，程序使用用户的 Windows 语言启动（设置 → 时间和语言 → 语言）。如果 Windows 语言不在程序的 11 种语言之内，则以英语启动。
- 之后如果用国旗选择了其他语言，该选择会被保存，并在每次重启时生效（意大利语也是如此）。
- 在 4.10 或 4.11 中选择过意大利语的用户，只有在 Windows 为意大利语时才会再次看到意大利语；否则只需用国旗选择一次即可。

### 翻译
- “是”和“否”（扫描列等）以及起始页上的许可证名称，现在在所有语言中均已翻译。

### 安全
- 修正 GitHub 自动代码分析（CodeQL）报告的问题：向电台存储器写入数字、通过环境变量指定的数据文件夹、固件说明文字、校验工具。

### 代码仓库和网站
- 代码仓库主页改为英文 README（意大利语原文在 `README.it.md`），带有 11 种语言的国旗、徽章和程序截图。
- 安全策略（“Security”标签页）改为英文，并附有其他 10 种语言的翻译。
- 网站：更新文字，加入社交网络预览图，并在每次发布时自动通知搜索引擎（IndexNow）。
