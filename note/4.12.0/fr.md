IU0VYT Flash V.4.12.0 pour Microsoft Windows 10/11

### Langue au premier démarrage
- À la première ouverture, le programme démarre dans la langue de Windows de l'utilisateur (Paramètres → Heure et langue → Langue). Si la langue de Windows ne fait pas partie des 11 du programme, il démarre en anglais.
- Si vous choisissez ensuite une autre langue avec les drapeaux, le choix est enregistré et vaut à chaque redémarrage (l'italien aussi).
- Qui avait choisi l'italien avec la 4.10 ou la 4.11 ne le retrouve que si Windows est en italien ; sinon, il suffit de le choisir une fois avec le drapeau.

### Traductions
- « Oui » et « Non » (colonne Balayage et autres) et le nom de la licence sur la page d'accueil sont maintenant traduits dans toutes les langues.

### Sécurité
- Corrections des signalements de l'analyse automatique du code de GitHub (CodeQL) : écriture des nombres dans la mémoire de la radio, dossier des données indiqué par une variable d'environnement, texte des instructions du firmware, outils de vérification.

### Dépôt et site
- README en anglais sur la page principale du dépôt (original italien dans `README.it.md`), avec les drapeaux des 11 langues, les badges et les images du programme.
- Politique de sécurité (onglet « Security ») en anglais, avec les traductions dans les 10 autres langues.
- Site : textes mis à jour, image d'aperçu pour les réseaux sociaux et avis automatique aux moteurs de recherche (IndexNow) à chaque publication.
